# 星幕工坊

一款面向 Windows 的本地优先漫剧制作工作台，使用 React、Vite 和 Electron 构建。

当前版本：`1.37.0`。

当前版本覆盖完整创作链路：

- 故事启动台与最近项目
- 项目总览与剧集状态
- 剧本完成后的一键整部制作：自动匹配角色音色、补齐图片、生成台词配音与镜头视频，并在本机导出每集 MP4
- 剧本场景编辑
- 角色设定、参考图导入与 API 图片请求预览
- 统一素材库：集中查看、检索、定位、替换和移除真实图片、视频与音频
- 分镜编排、连续性信息与当前镜头 API 图片请求预览
- 台词与配音工作区
- 成片预览、真实本地 MP4 采用与导出、真实末帧连续性及当前镜头 AI 视频请求预览
- 剧本、图片、配音、视频 Provider 接口设置
- 顶部本地搜索可定位项目、角色、场景、分镜和台词

## 本地项目

版本 `1.18.0` 已支持真实的本地项目工作流：

- `1.24.0` 起首次启动保持真实空白，不再内置项目、模板、故事、角色、场景、分镜、台词或配音示例
- `1.25.0` 补齐 Windows 原生“文件”菜单：新建项目、打开项目、保存、另存为和退出，并支持 `Ctrl+N`、`Ctrl+O`、`Ctrl+S`、`Ctrl+Shift+S`
- `1.26.0` 新增独立素材库，直接从角色、分镜、台词和成片音轨派生真实素材索引，不创建第二套媒体数据或演示内容
- `1.27.0` 在角色模块增加“API 生成角色图”入口，使用当前角色真实字段生成可编辑请求预览；当前付费硬锁下不发送图片生成请求
- `1.28.0` 在分镜模块增加“API 生成当前画面”入口，使用当前镜头、场景和角色真实数据准备请求；图片执行器与付费生成继续硬锁
- `1.29.0` 在成片模块增加“AI 视频请求预览”入口，使用当前镜头真实首帧、下一镜头可选尾帧和本地导演提示词准备视频参数；不会上传素材、创建任务或消耗额度
- `1.30.0` 支持把用户本地 MP4 标准化为无源音轨的托管副本，采用到当前镜头并参与真实预览与导出；真实末帧可显式承接下一镜头，视频本体不嵌入 10 MB 项目文件，所有付费生成仍保持硬锁
- `1.31.0` 新增便携项目与安全清理：可把 `.manju`、真实托管镜头视频、SHA-256 清单和说明导出为 `.manju-bundle` 文件夹，并在另一台 Windows 电脑上校验后作为新副本导入；空间清理会比对当前项目、自动保存和全部恢复点，只把确认未引用的托管媒体移入 Windows 回收站
- `1.32.0` 将新导出便携包升级为 Manifest V2：V2 可直接校验导入，V1 通过内置纯函数迁移器转换后作为新副本导入；V3 及更高版本只读取大小受限的 manifest 摘要并阻止写入，不读取项目正文或媒体，不提供强制导入
- `1.33.0` 将成片制作升级为分集工作区：每集独立保存镜头编排、字幕、BGM/音效、字幕样式、撤销历史、恢复点与导出记录；旧版单集项目直接迁移，旧版多集项目的全局字幕和音轨以只读“旧版全项目成片”保留，不猜测归属；首次覆盖 V1 源文件前自动建立同目录备份
- `1.34.0` 接通百炼受控生成：剧本、角色设定、角色图、场景设定、场景图和单镜头分镜图均采用“预检—费用提示—明确确认—单次生成—本地留档—手动采用”，图片固定 `n=1`，不自动批量或重试
- `1.35.0` 将百炼生成的角色图、场景图和分镜图改为受控本地文件引用：已下载但未采用的结果可零调用恢复，采用时项目正文通常只增加数百字节，不再把整张 Base64 图片重复写入 10 MB 项目文件；角色连续性引用和视频首尾帧可直接复用该本地资产
- `1.36.0` 新增“剧本后一次确认、整部顺序制作”：只为当前真实项目中缺失的角色图、场景图、分镜图和镜头视频建立任务，按角色 → 场景 → 分镜 → 视频单并发执行，成功后自动采用本地资产；队列支持暂停、继续、停止和异常恢复，不自动重试。首次使用必须确认已在百炼为 `qwen-plus`、`qwen-image-2.0-pro`、`wan2.7-i2v-2026-04-25` 开启“免费额度用完即停”，遇到免费额度、余额不足或欠费错误会停止整队
- `1.37.0` 将配音与最终成片纳入同一次一键制作：角色按性别、年龄和性格自动匹配 `qwen-audio-3.0-tts-flash` 官方音色，角色页可手动更换；每句真实 WAV 会立即下载到本机托管目录，镜头视频和配音随后由本地 FFmpeg 合成为分集 MP4。图片请求主动间隔 31 秒，遇到明确限流会冷却 65 秒并最多自动重试 3 次；免费额度、余额或欠费错误仍立即停止整队，不切换模型
- 原生菜单“新建项目”会先确认并保存当前本机自动草稿，不删除或覆盖已另存的 `.manju` 文件；空白状态下保存会提示先创建或打开项目
- 首页和各制作工作区只展示用户输入、导入或保存的本机数据；识别到旧版内置演示自动保存时会忽略它，不覆盖用户自己的项目
- 输入故事后只创建一集、一个空场景的最小本地项目，角色、分镜、台词、图片与音频均由用户后续真实添加
- 新建项目后自动保存到应用数据目录
- 通过原生 Windows 对话框保存或另存为 `.manju`
- 打开 `.manju` 并恢复剧本、角色、分镜和配音数据
- 首页展示手动保存过的最近项目
- 项目总览支持行内修改显示名称、键盘确认或取消、80 字符与 10 MB 预检；改名不会重命名磁盘文件
- 未保存项目使用稳定的本地标识隔离时间线恢复点，修改显示名称不会丢失已有恢复记录
- 角色参考图可写入项目文件，单图限制为 2 MB
- 剧集支持新增、重命名、删除和上下排序
- 场景归属于具体剧集，支持新增、重命名、删除和上下排序
- 场景天气和主要角色已成为真实 `.manju` 数据；旧项目缺失字段会安全补空，不再伪造固定“小雨”或默认前两名角色
- 主要角色支持本地搜索、多选、场景出现提示、取消零副作用、键盘操作和完整候选项目 10 MB 预检
- 场景预计时长会优先合计当前分镜时长；没有分镜时按动作、旁白和台词执行确定性本地估算，并明确显示来源
- 分镜就绪度按环境、动作、叙事、主要角色和分镜草稿五项等权计算，不再固定显示 `60%`
- 剧本页右侧已移除无实际意义的“保存场景”，改为真实自动保存说明及“查看当前分镜 / 生成分镜草稿”上下文入口
- 角色支持新增、重命名、属性编辑、删除和上下排序
- 角色页提供始终可发现的“API 生成角色图”入口，可查看实际 Provider、模型、Key、付费锁、当前真实参考图和确定性提示词，并能直达图片设置
- 角色页声音入口会进入配音页并保持当前角色筛选，不再显示无行为的播放按钮
- 分镜归属于具体剧集和场景，支持筛选、新增、拆分、编辑、删除和上下排序
- 分镜页提供“API 生成当前画面”入口，可查看实际 Provider、模型、Key 状态、当前真实镜头图、提示词及最多 3 张连续性参考图，并直达图片设置
- 成片页为当前镜头提供“AI 视频请求预览”入口；仅在存在真实首帧时可用，并展示可选下一镜头尾帧、导演提示词、负向提示词、首帧/首尾帧模式、分辨率及 API 整数时长映射
- 视频请求预览只读取 `.manju` 中的真实镜头、场景和角色字段，不创建模拟视频、任务 ID、进度或完成状态；本地配音、BGM 和音效不会作为驱动音频上传，仍在最终本地 FFmpeg 导出时混音
- 台词归属于具体剧集和场景，支持筛选、新增、编辑、删除和上下排序
- 剧本页“整理剧本”已成为纯本地规则工具，可清理控制字符、换行、制表符、首尾空白和重复空行，不调用 AI 或网络接口
- 整理前可选择动作、旁白和角色台词范围，并通过前后差异、规则统计、类型筛选、质量诊断和逐项排除确认最终改动
- 补全句末标点为可选规则且默认关闭；URL、Windows 路径、纯数字、舞台说明和表情符号等特殊文本不会被误补标点
- 整理影响已有配音时必须再次确认，并完整重置受影响台词的音频、时长、状态与更新时间；现有分镜保持不变
- 整理提交前会对完整候选 `.manju` 执行 10 MB 预检，成功后进入既有 800 ms 自动保存流程
- 剧本页支持从 `角色：台词`、`角色（情绪）：台词` 等显式格式完全本地拆分台词，不调用 AI 或网络接口
- 拆分结果可先逐行预览、修正角色与情绪、排除旁白或异常行，并提示与当前场景重复的台词
- 默认追加并同步到配音页；替换模式会明确提示现有台词及音频影响，提交前执行 10 MB 候选项目预检
- 剧本页与配音页共享同一份角色台词，剧本中的文字、说话人和删除操作会实时同步
- 剧本台词发生修改后自动重置为“未配音”，避免继续使用已经过期的配音状态
- 场景动作描述和旁白作为真实项目数据自动保存，并兼容旧版缺失字段的 `.manju` 文件
- 支持将当前场景的动作、旁白和角色台词在本地转换成分镜草稿，不会调用外部 AI
- 重新生成已有场景的分镜草稿前会明确确认，避免静默覆盖已有镜头
- 每个分镜拥有可编辑的画面提示词，可根据动作、场景、镜头语言和连续性设定在本地重建
- 分镜可绑定一个或多个角色参考，记录服装设定并切换连续性锁定状态
- 旧版分镜会自动推断出镜角色并补齐提示词、服装及连续性字段
- 支持为镜头导入、替换或移除本地图片，单张图片限制为 2 MB 并嵌入 `.manju`
- 仅有真实图片 Data URL 的镜头才会显示“已完成”；旧项目中的无素材完成态会安全归一为“未生成”
- 图片执行器仍保持未开放；角色页和分镜页只展示真实请求配置，提交按钮明确锁定，批量生成继续禁用，不会发送图片请求或创建本地模拟队列
- 分镜卡片、镜头检查器和成片预览会优先显示已经导入的真实镜头图片
- 顶部“素材”进入独立素材库，可按角色图片、分镜图片、角色配音、背景音乐和音效分类，并支持名称、角色、场景和台词搜索
- 素材详情展示真实文件名、格式、容量、来源、更新时间与使用位置；定位会进入对应角色、分镜、配音或成片页面
- 替换素材前展示新旧文件和影响位置，提交前复用完整 `.manju` 10 MB 预检；移除图片或配音只清除媒体字段并保留角色、镜头和台词实体
- 素材库的音频缩略区只显示真实解析并保存的波形；没有波形时使用明确音频图标，不生成随机波形
- 支持为每句台词导入或替换本地音频，单个音频限制为 3 MB 并嵌入 `.manju`
- 配音页提供真实本地试听台：播放、暂停、进度拖动、实时双时间、音量、静音及当前筛选范围内的上一条/下一条均绑定同一媒体播放器
- 只有实际导入且可解码的本地音频才可试听；无音频的旧完成态会显示“无真实音频”或“未导入”
- 切换台词、场景或离开配音页会暂停并释放旧播放器，损坏音频进入可恢复错误态；应用 CSP 仅为本地音频增加 `media-src 'self' blob: data:`
- 配音 Provider 未接入时，音色、情绪、语速、音调和停顿控件明确锁定为接口预留，不影响本地导入音频
- 配音生成与批量生成入口在 Provider 未接入时保持禁用，不创建模拟音频、模拟波形或模拟完成状态
- 修改台词内容、说话人或情绪后会标记已有配音状态过期，避免误用旧音频
- 成片页会按镜头顺序与时长建立真实时间线，并显示每个镜头的起止时间
- 镜头可通过拖拽手柄直接重排，时间线右侧手柄可将单镜头时长调整为 0.5 至 30 秒
- 键盘可用 `Alt+左/右方向键` 重排镜头；时长手柄支持方向键按 0.1 秒微调，按住 Shift 时按 0.5 秒调整
- 镜头重排或改时长后，绑定字幕、角色配音、音效与播放头会同步映射；背景音乐保留绝对起点
- 镜头顺序和时长纳入撤销、重做、自动恢复点及 `.manju` 项目保存，旧版动态时间线标识会自动兼容
- 成片时间线支持镜头多选，普通点击、选择框、`Ctrl+点击`、`Shift+点击` 和 `Ctrl+A` 可完成追加、连续范围或全选
- 批量编辑栏可一次统一多个镜头的时长、画面运动、动效强度、转场方式和转场时长，未启用字段不会覆盖原值
- 一次批量提交只记录一个撤销步骤；撤销、重做和恢复点会同步还原全部目标镜头及其关联字幕、配音和音效时间
- 多选镜头可通过任一已选镜头握把成组拖动，非连续选择会按原相对顺序收拢后插入目标位置；`Alt+Shift+左/右方向键` 可按相邻未选镜头步进移动
- 组拖动会显示“移动 N 个镜头”毛玻璃徽标、目标位标签与整组弱化反馈；全选状态保持顺序不变并禁用组移动
- 一次成组移动只记录一个撤销步骤，字幕、角色配音、音效与播放头会从旧时间线一次映射到最终时间线；背景音乐保持绝对起点
- 多选镜头支持“删除所选”和 `Delete` / `Backspace` 快捷键；删除前会展示镜头、时长、关联字幕与音效影响，默认焦点停在取消按钮
- 确认删除前必须先建立本地恢复点；恢复点失败时不会删除，成功后可通过 8 秒提示条、`Ctrl+Z`、操作历史或恢复点找回
- 删除会同步压缩字幕、角色配音、音效与播放头时间，背景音乐保留绝对起点；全部删除后显示分镜引导空态并停用导出
- 删除事务完整保留镜头图片、提示词、角色绑定和连续性字段，撤销、重做与 `.manju` 自动保存均可恢复；源台词、角色、剧集和场景不受影响
- 多选镜头支持“复制所选”和 `Ctrl+D`：单选、连续或非连续选择会按原顺序形成副本组，并插入最后一个所选原镜头之后
- 镜头副本完整保留图片 Data URL、提示词、角色绑定、服装、连续性、时长、动效与转场；现有台词记录不复制，配音复用来源镜头的匹配结果
- 绑定字幕、完全位于镜头内的自由字幕及起点位于镜头内的 SFX 会同步复制；跨镜头自由字幕和 BGM 只保留原件
- 复制后只选中新副本组，第一个副本成为主镜头并定位播放头；8 秒提示条、`Ctrl+Z` 和操作历史支持一步撤销与完整重做
- 复制提交前会按完整候选 `.manju` 的 UTF-8 体积执行 10 MB 预检，超限时不修改镜头、字幕、音轨、历史或恢复点
- 成片时间线支持“拆分镜头”和 `Ctrl+B`：以当前播放头为切点，左右片段必须各保留至少 0.5 秒，多选、导出或拖动状态下自动停用
- 拆分不会改变成片总时长及后续镜头起点；右片段使用唯一 ID 并完整继承画面、提示词、角色、服装和连续性数据
- 拆分会连续保存画面运动区间、左右转场边缘与配音源偏移，预览和 FFmpeg 导出从正确位置继续播放，不会从头重复动效或台词
- 绑定字幕位于切点两侧时自动改绑，跨切点时拆成两条相邻同文字幕；自由字幕、BGM 与 SFX 保持原绝对时间且不复制
- 拆分提交前执行 10 MB 候选项目预检，并以单个权威历史事务支持提示条、`Ctrl+Z`、重做、恢复点与 `.manju` 自动保存
- 多选属于本地短生命周期界面状态，不写入 `.manju`；本版仍不提供持久分组
- 同剧集、同场景且文本一致的台词音频会自动绑定到对应镜头，避免跨场景误配
- 成片预览支持逐镜头选择、连续播放、进度跳转、字幕开关和音量控制
- 每个镜头可独立设置无动效、推近、拉远、左右或上下平移，并调整 5% 至 25% 的动效强度
- 镜头可独立选择直接切换或淡入淡出，淡入淡出时长可在 0.1 至 0.8 秒之间调整
- 镜头动效支持一键应用到全部镜头，且可通过时间线历史撤销、重做和从恢复点还原
- 成片预览会根据播放头实时模拟镜头运动，FFmpeg 导出则使用真实 `zoompan` 滤镜渲染
- 旧版 `.manju` 分镜会根据已有镜头运动文字自动推断动效，并补齐强度、转场和转场时长默认值
- 成片时间线支持导入最多 6 条本地背景音乐或音效，音轨会随 `.manju` 项目保存与恢复
- 每条音乐或音效可设置时间线起点、音量、淡入和淡出；背景音乐循环至片尾，音效按设定位置单次触发
- 导入音频时会在本机解析 48 段波形摘要并随项目保存，不上传原始素材或分析结果
- 每条音轨支持独立试听与停止，成片连续预览会按起点同步播放 BGM、音效和角色配音
- 音轨波形可用鼠标直接拖动或点击定位，键盘方向键也能以 0.1 秒步进调整起点
- 成片页提供独立字幕时间轴，可编辑每条字幕的入点、出点、多行文本，并支持新增、删除和从分镜台词重建
- 字幕块可在时间轴上整块拖动，左右边缘拉伸可直接调整入点和出点，所有结果都会写入 `.manju` 项目
- 选中字幕后可用左右方向键按 0.1 秒微调，按住 Shift 时按 0.5 秒步进移动
- 支持为全部字幕统一设置正向或负向时间偏移，并自动限制在成片时间轴范围内
- 支持在播放头或字幕中点拆分当前字幕，也可将当前字幕与相邻字幕合并
- 成片时间线提供撤销与重做，支持 `Ctrl+Z`、`Ctrl+Y` 和 `Ctrl+Shift+Z`，连续拖动会合并为单步操作
- 本次会话最多保留 40 步音轨与字幕操作历史，并显示编辑、撤销和重做记录
- 时间线编辑停止后会在本机自动建立完整项目恢复点，按项目隔离且最多保留 8 个
- 从恢复点还原音轨、字幕和字幕样式后仍可继续撤销，恢复文件不会上传到外部服务
- 支持通过 Windows 原生文件对话框导入或导出 UTF-8 SRT，单个文件限制为 512 KB，最多读取 500 条字幕
- 字幕支持字号、文字颜色、描边颜色、顶部/居中/底部位置、底色透明度和粗体设置，并随 `.manju` 项目保存
- 成片预览会实时反映字幕文本和样式，FFmpeg 会按独立字幕轨道与样式真实烧录，不再只能使用镜头原始台词
- 导出前会按真实文件动态统计画面、配音和字幕完整度
- 缺少画面、配音或启用中的字幕时，导出前会显示明确的降级影响确认；取消不会启动文件选择或渲染
- 内置 FFmpeg，可将镜头图片、台词音频、背景音乐、音效和中文字幕在本地合成为 H.264/AAC MP4
- 支持竖屏 1080×1920、横屏 1920×1080、逐镜头淡入淡出和直接切换
- 损坏或缺失的图片会自动降级为占位画面，损坏或缺失的配音会自动降级为静音
- 导出过程显示镜头渲染、时间线合并、字幕烧录和多轨混音进度，所有素材均留在本机
- 损坏或不受支持的音乐与音效会被安全跳过，原配音及其余有效音轨仍可正常导出
- 正在渲染的成片可以安全取消；程序会先等待 FFmpeg 退出，再清理临时文件
- 最近 12 条导出记录保存在应用数据目录，只记录路径、分辨率、时长、镜头数量和混音轨道数量
- 导出完成后可直接在 Windows 文件资源管理器中定位成片；已移动文件会明确标记
- 删除剧集或场景时同步清理关联分镜与台词，角色重命名时同步更新台词说话人
- 旧版 `.manju` 项目缺少关联字段时会自动迁移，空分镜或空台词状态可正常保存和回读

项目读写由 Electron 主进程处理，页面只能通过隔离的 preload API 调用限定能力，不能直接访问文件系统。项目文件限制为 10 MB，API Key 不进入项目快照。

## 接口状态

阿里云百炼 Key 已通过 Electron 主进程安全接入。主进程按顺序读取 `DASHSCOPE_API_KEY`、项目/工作目录 `key.txt`、应用程序同目录 `key.txt`；渲染页面只能读取脱敏状态和调用白名单鉴权探测，无法取得密钥、修改鉴权地址或把 Key 写入项目文件和构建产物。

当前能力边界：

- `script`：百炼 `qwen-plus` 的结构化剧本、角色设定和场景设定已接入；每次真实调用前必须先预检并由用户单独确认
- `image`：百炼 `qwen-image-2.0-pro` 已接入角色图、场景图和单镜头分镜图；固定单张、最多 3 张参考图、结果立即下载到本地，采用前检查项目 10 MB 上限
- `video`：百炼 `wan2.7-i2v-2026-04-25` 的真实异步生成、轮询、临时结果下载和本机托管已接入一键制作；单镜头高级入口仍保留请求预览
- `voice`：百炼 `qwen-audio-3.0-tts-flash` 非流式 WAV 已接入一键制作；临时音频只用于立即下载，本地落盘、校验通过后才标记完成

设置页“测试连接”会发送故意不完整的无生成请求，只验证 Key、区域和端点是否通过鉴权，不创建付费生成任务。真实一键制作只有在本地 Key 可用、用户确认已开启“免费额度用完即停”且环境未设置 `MANJU_DISABLE_PAID_GENERATION=1` 时才会执行；开发和自动测试统一设置该环境锁。软件无法读取控制台实时剩余额度，也不会伪造余额状态。

`key.txt` 已由 `.gitignore` 排除。不要把 Key 放进源代码、`.manju` 项目、截图、日志或安装包。

V22 设置页已重构为轻量 Provider 控制中心：四项能力使用键盘可操作的切换卡，同一时刻只挂载一套配置表单；保存、测试、未保存修改和本次会话日志均使用真实状态。设置页不再创建额外背景滤镜层，20 次进出场性能回归的热进入 P95 为 `33.4 ms`、退出 P95 为 `19.3 ms`，无大于 50 ms 的 Long Task。

本地 MP4 导出独立于视频 Provider：即使不配置任何 AI 接口，也可以使用已导入的图片和音频导出视频。FFmpeg 的版本、来源和许可信息见 `THIRD_PARTY_NOTICES.md`。
