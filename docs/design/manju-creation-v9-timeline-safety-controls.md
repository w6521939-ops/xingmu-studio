# 成片时间线安全编辑控件 Design Spec

## 1. 整体页面分析

- 视觉来源：`docs/design/manju-v8-launchpad-final-assembly.png` 与 Electron 实际运行截图 `outputs/runtime/final-subtitles.png`。
- 参考画布：设计图约 `1586 × 992 px`；运行截图约 `1777 × 974 px`。
- 目标页面：项目内 `成片` 页的 `成片时间线` 区域。
- 页面目的：为音轨、字幕时间、字幕内容和字幕样式编辑提供可发现、可撤回、可跨重启恢复的安全操作入口。
- 保持既有天蓝色渐变、白色毛玻璃、深蓝文字和圆角体系；不新增深色剪辑器外壳，不扩展为多轨专业 NLE。
- 本次仅扩展时间线标题栏与一个折叠面板，不改变预览区、导出区、镜头带、音轨和字幕轨道的既有布局。

## 2. 页面结构拆解

## 3. 组件级设计稿

### 3.1 TimelineHeader

| 字段 | 规格 |
| --- | --- |
| 类型 | Header / Toolbar |
| 位置 | `ProductionTimeline` 顶部 |
| 宽度 | 约 `1680 px`；占运行画布宽度约 `94.5%`；占父容器宽度 `100%` |
| 高度 | 约 `44 px`；占页面高度约 `4.5%`；占时间线首屏高度约 `5%` |
| Padding | 水平 `2–4 px`，垂直 `0–4 px` |
| 对齐 | 左侧标题，右侧安全编辑动作；窄屏允许动作区换行 |
| 背景 | 透明，继承外层毛玻璃 |
| 状态 | 面板展开时动作区保持位置稳定，不产生横向跳动 |

### 3.2 UndoButton / RedoButton

| 字段 | 规格 |
| --- | --- |
| 类型 | Icon Button |
| 尺寸 | `36 × 36 px`；占屏宽约 `2.0%`；占标题栏高度约 `82%` |
| 点击区 | 不小于 `36 × 36 px` |
| 圆角 | `10 px` |
| 背景 | `rgba(255,255,255,.48)`；悬停使用浅天蓝渐变 |
| 边框 | `1 px rgba(73,174,232,.24)` |
| 图标 | 语义为向左/向右回转箭头，约 `15 × 15 px`；占按钮高度约 `42%`；缺失时用文字 `↶ / ↷` |
| 状态 | 可用、hover、pressed、focus-visible、disabled；禁用时透明度约 `42%` |
| 辅助信息 | `title` 与 `aria-label` 明确显示 `撤销 Ctrl+Z`、`重做 Ctrl+Y` |

### 3.7 OperationHistoryList

| 字段 | 规格 |
| --- | --- |
| 类型 | Compact List |
| 单行高度 | `28–32 px`；约占面板高度 `23%` |

| 字体 | 主文案 `12 px / 18 px / 600`；时间 `11 px / 16 px / 400` |
| 状态 | 最新项使用天蓝左边线；撤销使用低饱和蓝灰；重做使用亮天蓝 |
| 空态 | `还没有时间线操作`，不显示伪记录 |

| 字段 | 规格 |
| --- | --- |
| 类型 | Compact List + Restore Button |
| 单行高度 | `34–38 px`；约占面板高度 `27%` |
| 内容 | `自动恢复点`、建立时间、项目名、按钮 `恢复` |
| 恢复按钮 | 约 `58 × 28 px`；占列表列宽约 `12%`；点击前使用原生确认框 |
| 数量 | 最多保留 8 个，按时间倒序 |
| 失败态 | 显示橙色提示 `恢复点保存失败`，不影响当前项目自动保存 |

## 5. 设计规范总结

- 颜色：沿用 `#F4FBFF → #D7F1FF → #74CAFF` 天蓝渐变；主文字 `#12324B`；焦点 `#198FDC`；错误/失败使用低饱和橙色。
- 字体：沿用 Windows 系统无衬线；按钮不低于 `12 px`，历史时间不低于 `11 px`。
- 间距：以 `4 / 8 / 12 / 16 px` 为节奏；动作区间距 `6–8 px`。
- 圆角：图标按钮 `10 px`，文字按钮 `12 px`，折叠面板 `14 px`。
- 阴影：只使用现有轻蓝外阴影与玻璃内高光，不增加黑色重阴影。
- 键盘：`Ctrl+Z` 撤销，`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做；输入框聚焦时也由时间线历史统一处理。
- 历史范围：音轨增删与参数、音轨起点拖动、字幕增删/导入/重建/拆分/合并/拖动、字幕文本与样式。
- 自动恢复：编辑停止后短暂延迟建立；最多 8 个；完整项目快照仅保存在本机用户数据目录。
- loading：恢复点按钮显示 `正在建立…`；恢复期间对应按钮禁用。
- empty：历史与恢复点分别显示独立空态。
- error：恢复点失败只在面板与全局通知中提示，不阻塞继续编辑和项目自动保存。
- disabled：无可撤销/重做状态时按钮必须禁用，不允许点击后无反馈。
- selected/pressed：使用天蓝描边、轻微内高光和 `aria-expanded` 表达。
- 小屏：宽度小于 `1180 px` 时动作区换行；面板改为单列，历史在上、恢复点在下。
- 长文本：历史标签单行省略，完整文案放入 `title`；项目名最多显示一行。
- 暗色模式：当前版本仍以亮色主题为准；若系统强制高对比，保证原生焦点轮廓与文字对比。
- 横竖屏：Windows 桌面横向窗口为主；窗口变窄时不得遮挡镜头带。
- 安全区：底部沿用页面滚动容器的 `24 px` 留白，不新增固定悬浮层。

## 8. 不确定项与推测值

- V8 原图没有历史面板，本次位置和尺寸属于在既有视觉系统内的功能性推测值。
- Windows 不同缩放比例会影响实际像素尺寸，开发以 CSS 响应式比例和最小点击区为准。
- 恢复点文件大小取决于用户嵌入的图片和音频；实现需继续遵守现有单项目 `10 MB` 上限与有界保留策略。
