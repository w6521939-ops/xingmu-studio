# 成片页镜头排序与时长联动 Design Spec

## 1. 整体页面分析

- 视觉来源：`docs/design/manju-v8-launchpad-final-assembly.png`、`outputs/runtime/final-shot-motion.png`、`docs/design/manju-creation-v9-timeline-safety-controls.md` 与 `docs/design/manju-creation-v10-shot-motion-controls.md`。
- 参考画布：运行截图 `1777 × 974 px`；Windows 桌面横向窗口；页面为纵向滚动，无移动端状态栏或底部安全区。
- 目标页面：项目内 `成片` 页的 `ProductionTimeline`，仅扩展现有单层 `ShotTrack`；不新增专业 NLE 多轨编辑器。
- 页面目的：让用户直接拖动镜头改变成片顺序，通过镜头右边缘调整时长，并让字幕、角色配音与音效保持时间对齐。
- 视觉方向：继续天蓝渐变、白色毛玻璃、深蓝文字和轻量轮廓；拖动反馈使用发光插入线、半透明镜头幽灵和实时时长气泡，不引入黑色剪辑器背景。
- 本轮主分类：页面与布局；副分类：时间线状态与数据联动。

## 3. 组件级设计稿

### 3.1 ShotTrack

| 字段 | 规格 |
| --- | --- |
| 类型 | Horizontal Flex Timeline / Reorder Container |
| 位置 | `ProductionTimeline` 标题栏下方，镜头动效检查器上方 |
| 宽度 | 约 `1680 px`；占截图宽度约 `94.5%`；占父容器 `100%` |
| 高度 | 约 `116 px`；占页面截图高度约 `11.9%`；占时间线首屏区约 `14%` |
| 布局 | 镜头宽度按时长比例分配；最小可见宽度 `96 px`（推测值）；过长总时长时允许水平滚动 |
| 间距 | 镜头间 `8 px`；占父容器宽度约 `0.48%` |
| 背景 | 透明，继承外层毛玻璃 |
| 状态 | 默认、镜头拖动中、时长拉伸中、插入目标、键盘操作、禁用 |
| 实现提示 | 保持单层镜头带；使用 Pointer Events 而非 HTML5 Drag API，避免 Electron 中默认图片拖拽干扰 |

| 类型 | Timeline Segment Container |

## 4. 联动规则与数据边界

### 4.1 镜头排序

- 拖动修改项目 `shots` 的全局时间线顺序；镜头的 `episodeId`、`sceneId`、图片、台词、运镜和转场字段不变。
- 允许镜头跨场景排序，但不会把镜头重新分配到其他场景；分镜页仍按原场景筛选展示。
- 排序完成后保留 `selectedShot` ID，播放头移到该镜头新起点的原相对进度，避免突然切换镜头。
- 无实际顺序变化时不记录历史、不建立恢复点。

### 4.2 镜头时长

- 镜头时长以统一 `0.0s` 字符串形式回写既有分镜数据，拖动计算使用数值秒数。
- 范围为 `0.5–30.0 s`，步进 `0.1 s`；超出范围时就地限制，不报错中断。
- 时长改变后，后续镜头的起止时码、总时长、预览、FFmpeg 渲染、字幕轨与音轨均使用重算结果。
- 淡入淡出时长继续按镜头时长的三分之一自动限制，不修改用户保存的原始转场时长。

### 4.3 字幕同步

- 时间线镜头使用不含顺序索引的稳定标识 `timeline-{shotId}`；旧版 `timeline-{shotId}-{index}` 在读取或首次联动时归一化。
- 有 `sourceItemId` 的字幕明确跟随对应镜头；没有来源的导入/自定义字幕在操作开始时按“最大重叠时长，相同时取字幕中点所在镜头”建立本次临时绑定。
- 镜头排序时，字幕保留在所属镜头内的相对入点和出点比例，并随镜头移动到新起点。
- 镜头时长变化时，字幕相对入点和出点按镜头新时长等比例缩放；最短字幕时长为 `0.1 s`，且不超过成片总时长。
- 字幕文本、样式和 ID 不变；拖动后字幕列表重新按入点排序。

### 4.4 音频同步

- 角色配音由镜头的场景与台词绑定，不单独写入起点；重建时间线后自动跟随镜头。
- BGM 保持用户设定的绝对起点，因其属于全片音乐而不强制绑定单镜头；总时长缩短时起点自动限制在新片尾之前。
- SFX 在拖动操作开始时绑定其起点所在镜头，并保留相对该镜头的秒数偏移；镜头排序或改变时长后随镜头移动，偏移超过新镜头时长时限制在镜头末尾。
- 本轮不新增“绑定/解绑”高级开关；联动规则通过完成通知明确说明。

### 4.5 历史、恢复与保存

- 时间线历史快照扩展为保存 `shotTimeline`：只记录镜头 ID、顺序、时长和现有动效字段，不回退镜头图片、文案或其他业务数据。
- 一次完整拖动只记录一步；时长 pointer move 连续变化合并为一步。
- 历史文案使用 `重排镜头 02 → 01`、`调整镜头 02 时长`；撤销、重做同时还原镜头顺序/时长、字幕时间和 SFX 起点。
- 现有 40 步会话历史、8 个完整项目恢复点和 `.manju` 自动保存继续生效。
- 数据不出本机，不新增网络、权限、依赖或 Provider 接口。

## 6. 设计规范总结

- 颜色：底色沿用 `#F4FBFF → #D7F1FF → #74CAFF`；交互主色 `#22AEEB`；选中边框 `rgba(45,174,234,.82)`；禁用态 `#91A9B7`。
- 字体：Windows 系统无衬线；镜头号 `10 px / 700`；时码 `10 px / 700`；气泡 `11 px / 700`。
- 间距：继续 `4 / 8 / 12 / 16 px` 节奏；新增元素不改变时间线外层 padding。
- 圆角：镜头 `12 px`；握把 `8 px`；数值气泡 `8 px`。
- 阴影：只使用蓝色外发光和现有玻璃内高光，不增加黑色重阴影。
- 图标：拖动使用六点线性图标；缺失时使用 `⋮⋮`；时长使用双竖线手柄，无外部图标资源依赖。
- 按钮：镜头选择、拖动握把与拉伸手柄拆成同级互动元素，不产生嵌套按钮。
- 图片：继承现有 `Art` 的真实图片/占位降级，不修改裁剪策略。
- 输入：Pointer Events 使用 pointer capture；轨道失焦、`pointercancel` 或 `Escape` 时取消未提交操作。
- loading：无异步加载；拖动过程不触发保存或恢复点，仅在 pointer up 后提交。
- empty：无镜头时保留现有空态；不渲染握把或拉伸手柄。
- error：无效时长自动归一到 `0.5–30.0 s`；同步数据损坏时保留字幕和音轨的安全原值并显示通知。
- disabled：单镜头时禁用排序，但允许调整时长；导出中暂停结构性编辑，避免导出快照与界面发生偏差。
- selected：选中镜头保持现有三层天蓝轮廓；拖动中仍保留该镜头 ID。
- pressed：握把与手柄只做 `translateY(1px)` 及亮度变化，不改变宽高。
- permission denied：本功能不新增文件、媒体或系统权限。
- 长文本：镜头动作和台词不在轨道内展开；现有状态和时码必须保持可读。
- 小屏：小于 `1180 px` 时轨道启用水平滚动并保留镜头最小宽度；不将镜头压缩到无法操作手柄。
- 暗色/高对比：当前亮色主题不改；强制颜色模式下保留原生焦点轮廓和文本标识。
- 横竖屏：Windows 桌面横向编辑为基准；导出 9:16 或 16:9 不影响时间线交互。
- 底部安全区：继续使用页面滚动容器底部 `24 px` 留白；无新增固定浮层。

## 7. React 与服务层实现映射

| 设计区域 | 建议映射 | 责任边界 |
| --- | --- | --- |
| `ShotTrack` / `ShotSegment` | `FinalPage` 内拆出的局部 React 组件 | 只处理指针/键盘交互、预览态和语义化标记 |
| 排序与时长规则 | 新建 `src/services/shotTimelineEditService.js` | 归一化时长、重排镜头、重算镜头起点，不读写 DOM |
| 字幕/SFX 联动 | 同一服务或独立纯函数 | 输入旧时间线与新时间线，输出新字幕和音轨；可独立单测 |
| 历史 | `timelineHistoryService.js` | 扩展 `shotTimeline`，撤销/重做只合并顺序、时长和动效，不覆盖镜头其他字段 |
| 项目保存 | 现有 `projectModel` / `projectRepository` | 沿用 `shots` 数组顺序与 `duration` 字段，不改项目格式版本 |
| 导出 | 现有 `timelineService` / `videoExportService` | 消费重建后的顺序与时长；不增加新 Provider |
| 样式 | `App.css` 既有 `.production-timeline` 区域 | 只新增握把、插入线、拉伸气泡和拖动状态，不改全局主题 |

## 10. 不确定项与推测值

- V8 原图和 v1.8.0 运行截图都没有排序握把、拉伸手柄和插入指示线；这些尺寸为依据既有单层镜头带做出的功能性推测值。
- 默认允许跨场景重排但不改变场景归属，这是为了保留“成片顺序”与“剧本分组”两个独立概念。
- 未绑定字幕采用最大重叠镜头作为本次同步对象；BGM 保持绝对时间，SFX 跟随镜头，避免背景音乐因镜头排序而突然跳转。
- 当前产品未引入多选镜头、吸附标记、波纹剪辑或分组锁定；本轮不扩大到这些高级能力。
