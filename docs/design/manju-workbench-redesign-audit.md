# 漫剧制作工作台 V2 重设计审查稿

## 1. 整体页面分析

### 1.1 来源与页面目的

- 视觉来源：Electron 实际运行截图 `manju-workbench-runtime.png`。
- 截图尺寸：约 `1784 × 942 px`。
- 页面类型：桌面端 AI 漫剧制作工作台。
- 页面目的：承载主题扩写、角色/道具/场景记忆、图像组合、图生视频、尾帧续接、资源管理和一键成片。
- 当前技术栈：React + Electron + Vite。
- 本文只做设计分析与新版方向定义，不修改页面代码。

### 1.2 当前视觉判断

当前页面属于“通用深色 AI SaaS 仪表盘”风格：纯黑背景、大面积紫色强调、圆角卡片、左侧导航、顶部状态栏和统计卡片。它能表达功能，但不能表达“导演、分镜、镜头、创作过程”。

### 1.3 当前主要问题

#### 布局问题

1. 左侧导航约占屏幕宽度 `17.3%`，信息价值低，却长期挤占核心创作画布。
2. 页面主体从“标题—流程条—表单—统计卡”自上而下堆叠，更像项目配置页，不像制作台。
3. 主编辑区与预览区比例约为 `70% : 30%`，但左侧主要是文本表单，右侧真正的成片预览过小。
4. 流程条、页面标题、输入卡、预览卡、资产统计都在竞争第一视觉层级，主任务不明确。
5. 底部四个数字统计卡与“漫剧制作”关系弱，占用一整行，却没有直接操作价值。
6. 缺少创作工具应有的分镜轨道、镜头列表、素材拖拽区、连续性检查和时间线。
7. 顶部“一键成片”按钮与左侧“一键成片”导航重复，造成入口层级混乱。

#### 配色问题

1. 紫黑配色是典型生成式 AI 产品默认色，品牌辨识度不足。
2. 背景、侧栏、卡片之间都接近黑色，仅靠细边框区分，空间层级发闷。
3. 紫色同时用于 Logo、导航、标题装饰、按钮、数字和焦点，强调色失去强调作用。
4. 次级文字灰度过低，小字号与深色背景组合后可读性差。
5. 成功绿、紫色、蓝紫预览同时存在，视觉语言不统一。

#### 造型问题

1. 几乎所有容器都是圆角卡片，导致界面软、碎、像组件库示例。
2. 输入区、预览区、资产区没有“工作台器材”的结构感。
3. 预览画面使用抽象渐变和文字头像，无法支撑漫剧创作的沉浸感。
4. 图标线条、卡片边框、按钮高光都过于轻，缺少影视制作软件的精确感。

#### 字体与信息密度问题

1. 页面标题约 `40 px`，而大多数说明文字只有 `9–11 px`，比例跨度过大。
2. 中文正文偏小，部分功能说明不适合在桌面高 DPI 环境中阅读。
3. 英文装饰标题 `AI PRODUCTION PIPELINE` 对业务没有帮助，反而制造模板感。
4. 同一卡片内同时存在标题、标签、状态、说明和数字，信息密度碎片化。

## 5. V2 视觉方向候选

### 5.1 影视导演台（推荐）

- 气质：专业、克制、电影工业、长时间使用不疲劳。
- 背景：炭黑 `#151412`，而不是纯黑。
- 面板：暖灰黑 `#201F1C`、次级面板 `#292722`。
- 主文字：暖白 `#F1EEE7`；次文字 `#AAA59B`。
- 唯一品牌强调：朱砂红 `#D4523C` 或场记板红 `#E05A47`。
- 成功与连续性：低饱和苔绿 `#7F9B72`。
- 选中镜头：米白描边配朱砂角标，不使用紫色辉光。
- 圆角：面板 `4–6 px`，缩略图 `3 px`，主按钮 `4 px`。
- 阴影：仅浮层使用，工作区通过明度和分割线区分。
- 字体：系统无衬线为主；镜头号、时间码使用等宽字体。

### 5.2 苹果专业创作工具

- 气质：清晰、轻量、精密、接近 Final Cut / Logic 的现代工具感。
- 背景：中性石墨 `#1C1C1E`，面板 `#2C2C2E`。
- 强调：系统蓝 `#0A84FF`，仅用于选中和主操作。
- 圆角：`8–10 px`，但禁止所有区域都卡片化。
- 优点：易用、成熟、可读性高。
- 风险：品牌个性较弱，容易像通用桌面软件。

### 5.3 东方漫剧编辑台

- 气质：宣纸、墨色、朱印、分镜手稿，品牌辨识度最强。
- 背景：纸灰 `#E9E3D6` 或墨黑 `#171613`，支持明暗双主题。
- 强调：朱砂 `#B83A2F`、旧金 `#A18352`。
- 结构：大量直线、批注、镜头编号、印章式状态。
- 优点：适合国风、武侠、奇幻漫剧。
- 风险：如果以后覆盖现代、科幻题材，风格可能限制内容表达。

## 6. V2 设计规范总结

### 颜色规则

- 禁止紫色/粉色 AI 渐变作为品牌主视觉。
- 强调色只用于当前镜头、主要按钮、录制/生成状态。
- 面板层级至少有 `8–12%` 明度差，不依赖发光描边。
- 普通正文对比度至少 `4.5:1`。

### 字体规则

- 页面不再使用营销式巨型标题。
- 工具标题 `15–17 px / 600`；正文 `13–14 px / 400`；辅助文字不低于 `11 px`。
- 镜头号、时间码、帧数使用等宽数字。
- 中文优先，不使用无意义英文眉题。

### 按钮规则

- 每屏只有一个高强调主按钮。
- 工具按钮高度 `32–36 px`，重要操作高度 `40–44 px`。
- 图标 `16–18 px`，线宽统一 `1.8 px`。
- 禁用态、处理中、完成态必须同时使用文字和图标表达。

### 卡片与面板规则

- 不再用“每块内容一个圆角卡片”的方式组织页面。
- 主工作区采用连续画布、分割栏和可调面板。
- 素材以缩略图胶片条呈现，统计数字只作为角标。
- 圆角不超过 `6 px`，浮层除外。

### 图像与预览规则

- 中央视窗必须显示目标比例、安全框、字幕区和播放控制。
- 9:16 项目使用真实竖屏画布，不在横屏占位框中伪装。
- 没有真实素材时使用分镜线稿或胶片占位，不使用抽象紫色渐变球。

### 状态规则

- loading：画布顶部细进度线和镜头状态文字，不遮挡整个界面。
- empty：在对应轨道或素材条内出现，不使用大面积空态卡片。
- error：靠近出错镜头显示，时间线同时出现红色错误角标。
- disabled：降低明度但保留边界和标签。
- selected：米白或单一强调色描边，不使用辉光。
- pressed：位移 `1 px` 或背景明度变化。
- permission denied：本地上传入口显示原因和打开设置动作。

### 响应式规则

- `≥ 1280 px`：工具轨 + 镜头列表 + 中央画布 + 导演检查器。
- `960–1279 px`：镜头列表折叠为缩略图条，导演检查器改抽屉。
- `< 960 px`：不压缩画布；使用工作区 Tab 切换，底部时间线可横向滚动。
- 长文本仅在导演检查器内部滚动，不扩大整个页面宽度。
- 暗色和高 DPI 为桌面主场景；焦点环和 reduced-motion 必须保留。
