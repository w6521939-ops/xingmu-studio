# 漫剧制作工作台设计稿

## 1. 来源与基准

- 需求来源：用户提出的六项能力——文生文、文生图与角色/道具/场景记忆、图生图组合、图生视频与尾帧保留、资源标记与本地上传、一键成片。
- 视觉来源：当前仓库没有业务设计图或页面截图。`src/assets/hero.png` 经检查为 Vite 模板装饰图，不作为产品视觉基准，也不在新页面中使用。
- 产品类型：面向短剧/漫剧创作者的桌面端 AI 创作工作台。
- 技术基准：React 19 + Electron + Vite，不新增依赖，不接入真实 API；所有生成动作使用本地交互状态演示。
- 参考画布：桌面端 `1440 × 900`；Electron 窗口内容区不额外绘制系统状态栏。推荐窗口最小尺寸 `1080 × 700`。
- 响应式基准：`≥ 1180px` 为三栏工作台，`768–1179px` 收窄侧栏并将右侧栏下移，`< 768px` 改为顶部导航与单列内容。

## 2. 视觉方向

- 风格：深色电影制作台，偏专业创作工具，不使用娱乐化渐变堆叠或拟物按钮。
- 主色：创作紫 `#8B5CF6`；高亮紫 `#A78BFA`；成功绿 `#34D399`；提示琥珀 `#FBBF24`；危险红 `#FB7185`。
- 背景层级：应用背景 `#09090B`，侧栏 `#0D0D12`，工作面 `#111116`，卡片 `#17171F`，悬浮层 `#1D1D27`。
- 文本：主文字 `#F5F3FF`，次文字 `#A1A1AA`，弱文字 `#71717A`，边框 `rgba(255,255,255,0.08)`。
- 字体：系统无衬线 `Inter / PingFang SC / Microsoft YaHei / Segoe UI`；不加载在线字体，保证 Electron 离线可用。
- 形状：卡片圆角 `14px`，输入框 `10px`，主按钮 `10px`，标签使用胶囊形；避免大面积玻璃拟态。
- 动效：仅使用 `opacity` 与 `transform`，持续 `160–220ms`；系统启用减少动态效果时关闭过渡。

### 3.4 单项能力页

- 文生文：左侧编辑区占内容宽度 `64%`，右侧生成设置和章节状态占 `36%`。
- 文生图：资产类型筛选占顶部 `9%`；角色/道具/场景卡片网格占 `66%`；记忆库摘要占右侧或底部 `25%`。
- 图生图：素材选择区占左侧 `30%`，组合画布占中间 `44%`，参数与结果占右侧 `26%`。
- 图生视频：首帧/尾帧预览占左侧 `56%`，导演提示词、运镜、时长与“保留尾帧”设置占右侧 `44%`。
- 资源库：筛选和本地上传占顶部 `12%`，资源网格占 `88%`；每张卡片图片占卡高 `66%`，信息与“有用”按钮占 `34%`。

## 4. 组件清单与尺寸

- 品牌图标：`36 × 36px`，相对侧栏宽度约 `14%`；使用内联 SVG 场记板语义，不用 emoji。
- 导航项：相对侧栏宽度 `86%`、高度 `44px`；图标 `18 × 18px`，约占导航项宽度 `8%`。
- 页面标题：桌面 `28px/36px/700`，副标题 `13px/20px/400`。
- 主按钮：桌面最小 `148 × 44px`；内部图标 `18 × 18px`，图标宽度约占按钮 `12%`。
- 次按钮：最小高度 `40px`，触控目标不得小于 `44 × 44px`。
- 多行主题输入：宽度 `100%`，最小高度 `132px`；输入文本 `15px/24px`。
- 类型标签：高度 `32px`，水平内边距 `12px`，标签间距 `8px`。
- 流程卡：五列均分，单卡相对流程区宽度约 `18%`，卡间距合计约 `10%`。
- 资产卡：桌面三列；单卡相对父容器宽度约 `31.5%`，图片占卡片高度 `64–68%`。
- 预览画布：默认 `16:9`，相对预览卡宽度 `100%`；图标/占位插画占画布宽度 `16%`、高度 `28%`。
- “有用”标记：`36 × 36px` 图标按钮，必须同时提供 `aria-label` 与选中状态文字，不只依赖颜色。
- 本地上传：隐藏原生文件输入，以 `44px` 高按钮触发；支持 `image/*` 多选，选择后生成本地预览。

## 5. 间距与对齐

- 页面外边距：桌面 `28px`，约占主工作区宽度 `2.4%`；窄屏降为 `16px`。
- 卡片内边距：主卡 `20–24px`，小卡 `14–16px`。
- 栅格：主区 `12` 列，列间距 `16px`；模块内部优先使用 CSS Grid。
- 垂直节奏：`6 / 8 / 12 / 16 / 20 / 24 / 32px`。
- 所有标签和输入左对齐；按钮组右对齐；数字状态使用等宽数字特性。
- 卡片边框 `1px`，选中态增加主色描边与浅紫背景，不改变卡片尺寸，避免布局跳动。

## 6. 文本与图标

- 主品牌：`漫剧创作`；工作区标题：`漫剧制作工作台`。
- 六个导航名称：`一键成片`、`剧本扩写`、`角色与资产`、`画面组合`、`图生视频`、`资源库`。
- 图标语义：闪电/播放表示一键成片，文档表示剧本，人物卡表示角色资产，图层表示组合，摄影机表示视频，收藏夹表示资源库。
- 图标实现：统一 `20px` 线性 SVG，`stroke-width: 1.8`；缺失时使用同尺寸文字缩写占位，不显示破图。
- 示例主题文案：`一位失忆剑客在末日长安寻找自己的名字，却发现每恢复一段记忆，城中就会少一个人。`
- 导演提示词示例：`镜头从雨夜屋檐缓慢下摇，角色抬眼，衣摆被风吹起，最后停在握剑的手上。`

## 7. 状态与交互

- loading：生成按钮切换为进度状态并禁用重复提交；预览区显示静态骨架，不使用闪烁动画。
- empty：没有资产时显示用途说明和“本地上传”按钮，不显示空白网格。
- error：在操作附近显示带图标的错误文案，并通过 `role="alert"` 提示辅助技术。
- disabled：降低对比度但仍保留可识别文字；光标与 `aria-disabled` 同步。
- pressed/selected：按钮轻微下移 `1px`；选中导航、标签、资源同时用图标/文字和颜色表达。
- 角色/道具/场景记忆：卡片提供“已记忆/加入记忆”切换；记忆状态在模块切换后仍由 React 顶层状态保留。
- 图生图组合：选择一个角色、一个道具和一个场景后更新组合预览；未选齐时明确提示缺少项。
- 图生视频：导演提示词受控输入；默认开启“保留尾帧”，展示尾帧将用于下一镜头连续生成的说明。
- 资源标记：星标按钮可切换“有用”；资源库支持只看已标记。
- 本地上传：只读取浏览器本地对象 URL，不上传网络；支持多图并显示文件名。
- 一键成片：汇总五步状态；未完成项显示“待补充”，主按钮仍可演示流程但不发起 API。
- 长文本：标题两行截断，正文最多四行后滚动；输入框允许纵向扩展。
- 小屏：侧栏变为横向滚动顶栏，双栏/三栏布局折叠为单列；不产生页面级横向滚动。
- 暗色模式：当前版本以暗色为主；所有文本与交互元素按 WCAG AA 对比度校验。
- 横竖屏：桌面优先；窄竖屏保留核心输入和预览，资产详情下移。
- 安全区：底部固定操作栏时使用 `env(safe-area-inset-bottom)`；当前桌面实现不覆盖系统区域。
- 键盘：导航、标签、上传、收藏、生成按钮全部可聚焦；焦点环 `2px` 主色并偏移 `2px`。

## 8. React / Electron 实现映射

- `App.jsx`：仅负责当前模块、表单草稿、模拟生成状态、资产记忆/星标和本地图片 URL 等页面状态。
- `App.css`：应用壳层、导航、卡片、响应式、焦点与 reduced-motion 样式。
- `index.css`：设计 token、基础排版、重置和全局可访问性规则。
- `index.html`：提供 React `#root`、CSP 和页面标题。
- `main.js`：只调整桌面窗口尺寸；不加入业务逻辑、网络或文件系统能力。
- 未来 API 接入：剧本与生成逻辑下沉到 Service；资产读写进入 Repository；页面只消费统一状态和动作。
- 未来持久化：角色卡、道具、场景、资源标记和项目配置应由本地数据库或 Repository 保存；本轮只保存在内存中。

## 9. 本轮不实现

- 不调用大模型、文生图、图生图或视频生成 API。
- 不实现账号、云同步、计费、任务队列、真实导出和本地数据库。
- 不新增第三方 UI、图标或状态管理依赖。
- 不修改 Electron 权限、签名、打包或发布配置。

## 10. 不确定项与当前假设

- 将“接收导演提四次”理解为“接收导演提示词”。
- 将“最后一阵需要保留”理解为“上一段视频最后一帧需保留，作为下一段连续生成参考”。
- 当前未提供品牌 Logo、业务插画、角色图或目标设备截图，因此采用可替换的 SVG 图标与渐变占位画面。
- “一键成片”默认覆盖步骤 1–5，生成结果只做进度演示，不生成真实媒体文件。
