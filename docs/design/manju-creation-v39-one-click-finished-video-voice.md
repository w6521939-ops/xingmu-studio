### 1.3 目标用户

- 已有故事或剧本，希望尽量少操作就拿到完整视频的个人漫剧创作者。
- 不熟悉 Provider、任务轮询、素材采用、音轨和 FFmpeg 的非技术用户。
- 希望使用免费额度，明确不接受欠费和静默转付费的用户。

### 1.4 设计假设

- 默认输出以“每集一个 MP4”为交付单位；单集项目只生成一个 MP4。
- 一键流程复用用户已有真实素材，不覆盖已导入图片、视频或音频。
- “配音”页继续保留，但定位从必经步骤调整为高级检查与局部替换。
- “成片”页默认进入简洁模式，高级时间线和旧版内容继续保留在“高级编辑”中。
- 发行、平台上传、发布审核仍不在范围内。

## 2. 用户目标与验收标准

### 2.1 用户目标

```text
有剧本
  → 点击一次“一键生成整部成片”
  → 自动分配角色音色
  → 自动生成缺失图片
  → 自动生成台词配音
  → 自动生成镜头视频
  → 自动完成字幕、音画合成
  → 自动导出每集 MP4
  → 在成片页直接播放或打开文件位置
```

### 2.2 核心验收标准

1. 有合格剧本、角色、场景和分镜时，用户只需一次主操作即可开始完整生产。
2. 每个角色按性别、年龄、性格和声音气质自动选择不同音色。
3. 用户可在角色页手动更换某个角色的音色。
4. 已导入的真实本地音频不会被自动覆盖。
5. 生成配音下载到本地后才标记完成，远程 24 小时临时 URL 不写入项目。
6. 图片遇到限流时不立刻制造连续失败，界面显示冷却倒计时并自动恢复。
7. 图片失败导致的视频依赖缺失时，视频标记为“等待上游素材”，不记为视频失败。
8. 免费额度用完即停时整个队列立即停止，不切换模型、不转付费。
9. 全部必需任务成功后自动调用本地 FFmpeg，为每集输出可播放 MP4。
10. 默认成片页不再显示旧版只读卡、手动首末帧承接和重复的视频来源卡。

## 3. 百炼真实接口与 0 元边界

### 3.1 建议 TTS 模型

默认使用北京地域：

```text
model: qwen-audio-3.0-tts-flash
output: WAV
sample_rate: 24000
mode: HTTP 非流式
```

选择原因：

- 官方提供 HTTP 非实时语音合成，适合内容制作。
- 返回完整音频 URL，软件可立即下载到本地。
- 支持中文、英文和情感标签。
- 官方系统音色和 500 余个基础音色可用于角色差异化配音。
- 不需要采集用户声音，不进入声音复刻、声音设计和授权风险更高的流程。

### 3.2 官方现行边界

- 非实时 TTS 返回的音频 URL 有效期为 `24 小时`，必须立即下载、校验并本地托管。
- 北京地域 `qwen-audio-3.0-tts-flash` 当前按输入字符计费。
- 新人免费额度当前为 `1 万字符`，有效期规则由百炼控制台实际状态决定。
- 已认证账号若未开启“免费额度用完即停”，免费额度耗尽后可能继续扣费。
- 开启“免费额度用完即停”后，耗尽时返回
  `AllocationQuota.FreeTierOnly`，不会继续扣费。
- 软件无法可靠读取控制台实时剩余额度，因此不能展示伪造的“剩余免费字符”。

### 3.3 0 元安全门更新

V39 的模型确认签名增加语音模型：

```text
script:qwen-plus
image:qwen-image-2.0-pro
voice:qwen-audio-3.0-tts-flash
video:wan2.7-i2v-2026-04-25
```

首次启动完整一键成片前，安全弹窗必须明确要求用户确认四个模型均已开启“免费额度用完即停”。

弹窗只保存：

- 用户已确认；
- 确认时间；
- 模型签名；
- 本次预计图片、语音字符和视频任务数量。

弹窗不得宣称软件已自动检查控制台开关或剩余额度。

### 3.4 本次用量预估

一键开始前本地计算并展示：

- 图片：缺失图片数量；
- 配音：待生成台词数、合计中文字符数；
- 视频：缺失镜头视频数量；
- 导出：待导出剧集数。

若台词字符数超过 `1 万字符`：

- 不代表一定会收费，也不代表一定还有完整免费额度；
- 安全弹窗使用琥珀色提示：
  `本次台词共 12,480 字，超过该模型新人免费额度标称总量；只有确认控制台已开启“免费额度用完即停”后才能继续。`

### 3.5 不允许的行为

- 不自动关闭免费额度用完即停。
- 不自动切换到其他 TTS、图片或视频模型。
- 不自动购买资源包、充值或使用余额。
- 不创建自定义音色，不上传真人声音样本。
- 不把 API Key 写入 `.manju`、日志、截图或安装包。
- 不在软件启动、预览、测试和开发回归时调用生成接口。

## 4. 新的一键生产流程

### 4.1 用户可见的五阶段

为了减少理解成本，界面只显示五个阶段：

```text
1 角色定音
2 画面生成
3 自动配音
4 镜头视频
5 合成导出
```

内部任务仍保留更细的可恢复步骤。

### 4.2 内部任务顺序

```text
阶段 0　本地预检
  ├─ 检查项目、剧本、角色、场景和分镜
  ├─ 检查本地 Key 状态与四模型 0 元确认签名
  ├─ 统计缺失素材、台词字符和导出集数
  └─ 为上次中断任务恢复本地状态

阶段 1　角色定音
  ├─ 读取角色性别、年龄、性格、定位和 tone
  ├─ 从本地官方音色目录中确定性匹配音色
  ├─ 尽量避免主要角色重复音色
  └─ 保存 voiceId、voiceName、匹配原因和来源

阶段 2　画面生成
  ├─ 缺失角色图
  ├─ 缺失场景图
  └─ 缺失分镜图

阶段 3　自动配音
  ├─ 保留用户已导入的真实音频
  ├─ 为缺失或过期的台词生成 WAV
  ├─ 将情绪映射为模型支持的情感标签
  ├─ 下载到本地、校验 WAV、记录时长
  └─ 台词文本与音色未变化时直接跳过

阶段 4　镜头视频
  ├─ 只处理首帧已就绪的镜头
  ├─ 下载视频到本地
  ├─ 提取真实末帧并保留连续性
  └─ 不把上游素材缺失记成视频 Provider 失败

阶段 5　本地合成导出
  ├─ 按剧集编排镜头视频
  ├─ 按台词时间混合角色配音
  ├─ 自动写入字幕
  ├─ 用户已有 BGM/音效则复用，没有则不伪造
  ├─ 使用本地 FFmpeg 渲染
  └─ 每集输出一个 MP4 并保存导出记录
```

### 4.3 自动跳过与失效规则

| 资产 | 跳过条件 | 重新生成条件 |
| --- | --- | --- |
| 角色图 | 已有有效本地图片 | 图片缺失或用户主动要求替换 |
| 场景图 | 已有有效本地图片 | 场景设定变化且无用户锁定 |
| 分镜图 | 已有有效本地图片 | 分镜内容变化且无用户锁定 |
| 角色音色 | 已有手动音色 | 用户改回“自动匹配” |
| 台词音频 | 本地音频可播放且文本/音色哈希一致 | 台词、情绪或角色音色变化 |
| 镜头视频 | 已有有效受管 MP4 | 分镜首帧变化且用户确认重做 |
| 最终成片 | 导出输入哈希一致且文件仍存在 | 任一镜头、音频、字幕或设置变化 |

用户导入的本地素材优先级最高，一键队列默认只补缺，不覆盖。

## 5. 角色自动音色设计

### 5.1 角色数据补充

在现有角色数据上新增可选字段：

```text
gender: female | male | neutral | unknown
ageBand: child | teen | young | middle | senior | unknown
personalityTags: string[]
voiceMode: auto | manual
voiceModel: qwen-audio-3.0-tts-flash
voiceId: string
voiceName: string
voiceReason: string
voiceCatalogVersion: string
voiceUpdatedAt: ISO datetime
```

旧项目没有这些字段时保持兼容：

- `gender = unknown`
- `ageBand = unknown`
- `personalityTags` 从现有 `role`、`tone` 和 `relation` 提取本地候选标签
- 若仍无依据，使用中性叙事音色并标记“建议检查”

不得仅根据角色姓名猜测性别。

### 5.2 本地音色目录

- 安装包内置一份经过筛选的中文角色音色目录。
- 每个条目只保存官方公开的：
  - `voiceId`
  - 显示名称
  - 性别
  - 年龄段
  - 性格/声线标签
  - 语言
  - 适用模型
- 目录来源为百炼官方音色清单，不在运行时抓取网页。
- 实现阶段固定目录版本，并对模型与音色兼容性做单元测试。

### 5.3 自动匹配规则

候选音色先按中文和模型兼容性硬过滤，再评分：

| 条件 | 分数 |
| --- | ---: |
| 性别准确匹配 | `+40` |
| 年龄段准确匹配 | `+25` |
| 相邻年龄段 | `+12` |
| 性格标签重合 | 每项 `+8`，最高 `+24` |
| 与 `tone`、角色定位匹配 | 最高 `+12` |
| 主要角色使用未重复音色 | `+8` |
| 与已有主要角色重复 | `-18` |

相同输入必须得到相同结果，最终平分时使用 `character.id` 的稳定哈希决定，避免每次打开项目随机换声。

### 5.4 情绪映射

现有台词情绪转换为 TTS 文本标签：

| 项目情绪 | TTS 标签 |
| --- | --- |
| 默认、平静、冷静 | `[serious]` 或无标签 |
| 开心、兴奋 | `[excited]` |
| 悲伤 | `[sad]` |
| 生气 | `[angry]` |
| 惊讶 | `[amazed]` |
| 讽刺 | `[sarcastic]` |
| 好奇 | `[curious]` |
| 疲惫 | `[tired]` |

未识别情绪不擅自添加标签，以角色默认声音自然合成。

## 7. 页面二：角色页音色卡与更换抽屉

| VoiceIdentity | `w 100% / h 48 px` | 音色名、自动/手动徽标 |

### 8.3 限流不再显示为普通失败

## 9. 主动限流平滑策略

### 9.1 图片任务

官方当前对北京地域 `qwen-image-2.0-pro` 的任务提交限制为
`2 requests/minute`。

因此 V39 不再“一个任务完成后立即提交下一张”，而是：

- 同一账号、同一图片模型提交之间至少间隔 `31 秒`；
- 应用重启后从持久化的 `lastSubmittedAt` 继续计算；
- 如果其他应用或 Key 共享同一阿里云主账号，仍可能触发限流，此时进入自动冷却；
- 限流默认等待 `65 秒`，再重试同一个任务；
- 最多自动冷却重试 `3 次`，之后暂停等待用户稍后继续。

### 9.2 配音任务

官方当前对 `qwen-audio-3.0-tts-flash` 的任务提交限制为
`3 requests/second`。

为留出账号共享空间：

- 一键队列保持单并发；
- TTS 请求之间至少间隔 `500 ms`；
- 先下载并校验当前 WAV，再提交下一句；
- 限流时采用相同的冷却状态，不切换模型。

### 9.3 视频任务

官方当前对 `wan2.7-i2v-2026-04-25` 的任务提交 RPS 与并发限制均为 `5`。

V39 仍保持单并发，避免为提速引入额外费用与恢复复杂度。

## 13. 状态与交互

### 13.1 Loading

- 成片页骨架保持固定高度，避免布局跳动。
- 当前任务每秒更新倒计时时只更新文本节点，不重建大列表。
- 视频下载和本地导出分别显示真实阶段，不用一个无限旋转图标覆盖全部过程。

### 13.2 Empty

- 没有项目：`请先新建或打开项目`。
- 没有剧本：主按钮禁用，提供“前往剧本”。
- 有剧本但没有分镜：一键预检可调用本地拆镜能力时自动补齐；无法本地补齐时才阻塞。
- 没有台词：配音阶段显示“无需配音”，继续生成画面和视频。

### 13.3 Error

- Provider 鉴权失败：停止当前模型任务，其他模型不继续静默执行。
- 下载失败：远程 URL 未过期时只重试本地下载，不重新生成音频。
- WAV 校验失败：保留 Provider 请求 ID，标记该句失败，不采用损坏文件。
- FFmpeg 失败：保留已生成图片、配音和视频，只重试本地导出。
- 上游素材缺失：下游显示“等待上游”，不记为下游生成失败。

### 13.4 Disabled

- 运行中主按钮禁用并显示当前进度。
- 0 元确认签名与当前模型不一致时禁止继续，要求重新确认。
- 本地 Key 不可用时禁止真实调用，但允许查看项目和高级编辑。

### 13.5 Selected / Pressed

- 当前阶段：青蓝渐变底、白色图标。
- 已完成：薄荷绿勾选。
- 等待：浅蓝灰。
- 冷却：蓝紫色时钟和倒计时。
- 按钮按下只做 `translateY(1px)`，不做大幅缩放。

### 13.6 长文本

- 角色名最多显示一行，超出使用省略号和 title。
- 台词日志最多显示两行。
- 错误摘要最多两行，“查看详情”显示完整 Provider 错误。
- 不把长错误堆在成片页主视图。

### 13.7 小屏与响应式

`1000–1199 px`：

- 预览与生产中心改为 `62% / 36%`。
- 五阶段从带说明卡压缩为图标、标题和计数。

`<1000 px`：

- FinalMainGrid 改为单列。
- ProductionCenterCard 位于预览上方。
- 高级编辑打开独立全屏层。

### 13.8 暗色模式

- 背景改为深蓝青渐变。
- 毛玻璃表面使用 `rgba(12, 39, 58, .72)`。
- 文字、边框、禁用态、成功和错误颜色分别重新校准，不做简单反色。

### 13.9 横竖屏与安全区

- Windows 桌面默认横向窗口。
- 最终视频可选 `9:16` 与 `16:9`，默认沿用当前项目设置。
- 窗口内容底部保留 `20 px` 安全边距，抽屉 Footer 不遮挡系统任务栏。

## 15. 测试与验收计划

### 15.1 全程无真实生成的自动测试

- 角色音色匹配稳定性。
- 主要角色去重。
- 未知性别不按姓名猜测。
- 台词情绪标签映射。
- 本地音频优先与 AI 音频失效规则。
- 音频 24 小时 URL 只下载不持久化。
- 图片任务提交间隔至少 `31 秒`。
- `Throttling.RateQuota` 进入冷却而不是失败。
- 上游图片等待不会制造视频失败。
- `AllocationQuota.FreeTierOnly` 立即停止整条队列。
- 重启后从 `cooling-down` 或 `pending` 恢复。
- 全部资产就绪后触发一次本地导出。
- 旧版项目与本地音频仍可读取。

### 15.2 UI 自动验收

- 成片页默认不显示旧版卡、手动末帧和 AI 请求预览卡。
- 主按钮在 5 种状态下文案正确。
- 角色页可打开、筛选、试听和选择音色。
- 进度抽屉详细日志默认折叠。
- 冷却倒计时不会造成整页重排。
- `1000 × 700` 小窗口无横向溢出。
- 设置页进入退出不新增卡顿。

### 15.3 真实 API 验收

3. 试听确认真实可播放。

7. 验证限流时自动冷却。

## 16. 风险与不确定项

1. 百炼免费额度和模型价格会变化，最终以用户控制台和官方页面为准。
2. 软件不能读取控制台实时免费额度，0 元保护必须依赖控制台“免费额度用完即停”。
3. 官方基础音色目录包含 500 余个音色，实施时需固定并测试一份适合中文漫剧的本地子集。
4. 角色旧数据没有明确性别、年龄和性格字段，需要在角色页补充，但不强制阻塞旧项目。
5. 当前配音时间线以台词时长为基础，自动合成后需验证字幕和镜头时长冲突时的处理策略。
6. 多集项目默认每集输出一个 MP4；本轮不自动把多集合并为一条超长视频。
7. 当前导出代码主要由 `FinalPage` 驱动，实施时需要把可复用的本地合成编排下沉到主进程服务。
8. V39 只隐藏高级功能，不删除旧版项目数据或现有高级时间线能力。
