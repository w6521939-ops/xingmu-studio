# 漫剧创作 V36 · 受控提示词生成 Design Spec

## 1. 来源与基准

- 产品：Windows Electron 漫剧制作工作台，目标版本 `1.34.0`。
- 现有视觉基准：天蓝科技渐变、轻量毛玻璃、桌面三栏工作台；沿用角色页、剧本页、分镜页与新建项目页，不新增导航层级。
- 现有功能基准：
  - 新建项目页已有“故事灵感 → 结构化剧本”请求预检和费用确认。
  - 角色页已有角色图片请求预览，但执行器锁定。
  - 分镜页已有当前镜头图片请求预览，但执行器锁定。
  - 剧本页尚无当前场景的提示词生成入口和场景图片。
- API 基准：
  - 文本：`qwen-plus`，结构化 JSON。
  - 图片：`qwen-image-2.0-pro`，固定 `n=1`。
  - 图片结果必须立即下载到本地并写入连续性清单；项目只保存可验证的真实结果。
- 成本基准：所有真实文字、图片请求均可能计费；不承诺免费额度。界面必须在每次请求前单独确认，不提供批量生成和后台自动重试。

## 2. 产品目标

让用户在现有工作流中通过自然语言提示词完成第一阶段生成：

1. 故事提示词 → 完整项目剧本。
2. 角色提示词 → 当前角色设定。
3. 角色图片提示词 → 当前角色主视觉。
4. 场景提示词 → 当前场景设定与叙事内容。
5. 场景图片提示词 → 当前场景视觉参考。
6. 分镜图片提示词 → 当前镜头图片。

生成结果只能写回当前明确选中的业务实体；不得批量覆盖其他角色、场景或镜头。

## 3. 受控生成流程

```text
用户编辑提示词
  → 本地校验与请求预检
  → 展示模型、输入摘要、固定数量和官方参考费用
  → 用户点击“确认并生成”
  → 单次 API 请求
  → 校验结构或下载真实图片
  → 写入 .manju-studio 连续性资产
  → 用户选择“采用结果”
  → 检查项目 10 MB 上限
  → 仅更新当前实体并进入自动保存
```

硬性边界：

- 每次确认只允许一个请求。
- 图片固定生成 1 张。
- 不自动生成下一角色、下一场景或下一镜头。
- 失败不自动重试；用户可手动重试并再次确认。
- 关闭弹窗不采用结果。
- Key 仅由 Electron 主进程读取，Renderer 不接收密钥。

## 4. 页面与组件变更

### 4.1 新建项目页 · 剧本生成

- 保留现有故事灵感输入和确认弹窗。
- 调用状态从“付费生成已锁定”改为“单次确认后可生成”。
- 确认卡增加：
  - 模型 `qwen-plus`。
  - 最大输出 Token。
  - “文字模型按 Token 计费，实际免费额度以控制台为准”。
  - “本次只生成 1 个项目剧本”。
- 生成中禁用关闭和重复提交；失败停留在确认弹窗。

### 4.2 角色页 · 角色设定生成

- 左侧角色操作区新增次级按钮“AI 生成角色设定”。
- 点击打开 `CharacterProfileGenerationDialog`。
- 弹窗宽度：约 `760 px`，占 1440 px 画布宽度约 `52.8%`；最大高度约 `700 px`，占 900 px 画布高度约 `77.8%`。
- 内容：
  - 当前角色身份卡：名称、现有定位、现有关系。
  - 提示词输入：最多 `1200` 字符。
  - 将更新字段预览：角色定位、声音气质、人物关系、外貌、服装、禁止漂移项。
  - 请求预检与单次费用确认。
  - 结果对比：左列“当前值”，右列“生成值”。
  - 主按钮：“采用角色设定”；采用前不写入项目。
- 空提示词、Key 缺失、响应结构错误、项目过大均显示内联错误。

### 4.3 角色页 · 角色图片生成

- 复用 `CharacterImageApiDialog`，按钮状态由“已锁定”改为“单张生成”。
- 弹窗约 `920 × 650 px`；左侧参考图约占宽度 `34%`，右侧提示词与参数约占 `66%`。
- 固定：
  - 模型 `qwen-image-2.0-pro`。
  - 数量 `1`。
  - 尺寸 `1536 × 1024`。
  - 水印关闭。
- 有本地角色参考图时作为第 1 张参考图；提示词明确锁定身份。
- 确认区必须显示“官方参考价 0.5 元/张；免费额度是否可用以百炼控制台为准”。
- 成功后显示真实图片预览，用户点击“采用为角色主视觉”才更新当前角色。

### 4.4 剧本页 · 场景设定生成

- 编辑器标题区新增“AI 生成场景”按钮，与“拆分台词”“整理剧本”同级。
- 打开 `SceneGenerationDialog`，顶部为两个 Tab：
  - `场景设定`
  - `场景图片`
- 场景设定 Tab：
  - 提示词最多 `1600` 字符。
  - 读取当前剧集名、场景名、主要角色、故事梗概作为只读上下文。
  - 结构化输出字段：标题、地点、时间、天气、布局、灯光、色板、动作、旁白、台词建议。
  - 结果采用时只更新当前场景；台词建议以“追加”方式写入，不能静默覆盖已有台词。
- 弹窗约 `900 × 720 px`，结果区可滚动。

### 4.5 剧本页 · 场景图片生成

- 场景图片 Tab 使用当前场景设定自动草拟图片提示词，也允许编辑。
- 最多使用 3 张当前主要角色参考图。
- 固定单张生成；费用确认与角色图一致。
- 成功后显示真实场景图，采用后写入当前场景的 `image`、`imageSource`、`imageFileName`、`imageUpdatedAt`。
- 剧本页右侧场景信息面板增加 `16:9` 场景参考图卡；无图时显示空态。

### 4.6 分镜页 · 分镜图片生成

- 复用现有 `StoryboardImageApiDialog`。
- 当前镜头图优先占用参考位，其次按角色绑定顺序加入角色参考图，最多 3 张。
- “生成已锁定”改为“检查并生成 1 张”。
- 成功后展示真实图片与来源信息；“采用到当前镜头”只更新当前镜头。
- 生成后不得自动跳到下一镜头。

## 5. 共享确认与状态组件

### 5.1 `PaidGenerationConfirmation`

| 字段 | 规格 |
| --- | --- |
| 类型 | Modal 内确认区 |
| 宽度 | 父容器 100% |
| 内边距 | 14–18 px |
| 圆角 | 16 px |
| 背景 | 天蓝至白色毛玻璃渐变 |
| 信息 | Provider、模型、请求数量、参考费用、Key 脱敏状态、不会自动批量 |
| 按钮 | “返回编辑”“确认并生成” |
| 默认焦点 | “返回编辑” |
| 危险提示 | 琥珀色，不使用红色恐吓 |

### 5.2 状态机

- `editing`：编辑提示词。
- `review`：预检通过，等待单次确认。
- `submitting`：真实请求进行中，禁止重复点击。
- `result`：结构或图片已返回，但尚未采用。
- `applying`：执行项目大小检查并写回当前实体。
- `error`：显示错误码/信息，不自动重试。

### 5.3 交互与无障碍

- `Escape`：在 `editing/review/result/error` 关闭；`submitting` 阶段不关闭。
- Tab 焦点限制在当前弹窗。
- 成功结果用 `aria-live="polite"`；错误用 `role="alert"`。
- 长提示词和错误信息允许换行，不撑破按钮区。
- 1024 px 宽度改为单列；弹窗最大高度为 `calc(100vh - 32px)`。
- `prefers-reduced-motion` 下移除所有弹窗动画。

## 6. 数据与安全合约

### 6.1 角色设定输出

```json
{
  "role": "",
  "tone": "",
  "relation": "",
  "appearance": "",
  "costume": "",
  "forbiddenDrift": []
}
```

### 6.2 场景设定输出

```json
{
  "title": "",
  "location": "",
  "time": "",
  "weather": "",
  "layout": "",
  "lighting": "",
  "palette": "",
  "action": "",
  "narration": "",
  "dialogues": [
    { "speaker": "", "text": "", "emotion": "" }
  ]
}
```

### 6.3 图片结果

- 只接受 HTTPS 的阿里云结果地址。
- 下载后校验媒体类型、签名、大小与 SHA-256。
- 单张图片最大 `10 MB`。
- 写入 `.manju-studio/outputs/images/` 和 `manifest.json`。
- Renderer 只接收数据 URL、脱敏元数据和本地资产 ID。
- 项目快照超过 `10 MB` 时不采用，但已下载资产仍保留在本地连续性目录，供用户后续处理。

## 7. Design System

- 主色：`#35B9F0`、`#168FD0`。
- 背景渐变：`#EAF8FF → #CDEEFF`。
- 玻璃卡：白色 `72–90%`，边框白色 `70%`，阴影 `0 20px 55px rgba(18, 116, 165, 0.14)`。
- 正常文字：`#123D58`；次级文字：`#65879A`。
- 成功：`#0B8B7C`；警告/费用：`#A66A16`；错误：`#B64E48`。
- 圆角：按钮 `12 px`、卡片 `16 px`、主弹窗 `24 px`。
- 最小按钮高度：`38 px`；主要确认按钮 `44 px`。
- 不使用全屏背景滤镜；避免再次触发 Electron 合成层卡顿。

## 9. 验收标准

1. 四个入口均先本地预检，再单次确认。
2. 任何页面都不存在批量生成按钮。
3. 取消确认时真实请求数为 0。
4. 同一确认不能重复提交。
5. 角色设定只更新当前角色。
6. 场景设定只更新当前场景；台词只追加，不覆盖。
7. 角色图、场景图、分镜图均固定 `n=1`。
8. 图片结果下载并通过类型、大小和哈希校验后才可采用。
9. 生成成功但未点击采用时，项目数据不变化。
10. 项目超过 10 MB 时拒绝采用并给出真实错误。
11. Key 不进入 Renderer、项目文件、日志、安装包或错误文本。
12. 真实接口专项测试使用注入响应或 `--dry-run`，验收阶段不产生付费生成。

## 10. 设计识别与实现置信度

- 产品流程：`98%`
- 现有页面结构：`98%`
- 视觉系统：`97%`
- API 请求结构：`96%`
- 费用展示：`92%`，价格与免费额度可能变化，界面必须提示以百炼控制台为准。

本规格基于当前真实代码、现有运行截图和阿里云官方接口说明。V36 实现必须保持单次确认、真实结果本地化与不自动批量三条核心边界。
