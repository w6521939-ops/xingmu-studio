# 漫剧创作 V23 产品验收 P1 修复 Design Spec

## 1. 来源与基准

- 产品：Windows Electron 漫剧制作软件「漫剧创作」1.20.0。
- 视觉来源：`outputs/runtime/home.png`、`overview.png`、`character.png`、`final.png`。
- 参考画布：1783 × 942 px，Windows 桌面窗口，当前截图无独立系统状态栏。
- 既有视觉基准：天蓝渐变、明亮毛玻璃、轻科技感、顶部导航、系统无衬线中文字体。
- 本轮范围：修复验收中确认的四项交互真实性问题；不改变全局布局，不接入外部 AI Provider，不改项目文件格式。
- 发布签名属于发行流程，不属于本 UI 设计稿；没有代码签名证书时继续明确标记为发布阻塞项。

## 2. 整体页面分析

本轮不是全页面改版，而是在保持 V22 视觉体系的前提下，将看似可用但没有真实结果的控件改为可验证闭环：

1. 顶部搜索必须返回真实本地结果，并能跳转到对应页面。
2. 项目概览的故事简介必须真正展开和收起。
3. 角色页的声音入口必须进入配音流程，不再显示无行为的播放按钮。
4. 素材不完整时导出 MP4 必须先经过明确确认。

设计关键词：`truthful interaction`、`local-first`、`sky-blue glass`、`low interruption`、`recoverable action`。

## 4. 组件级设计稿

### 4.1 本地搜索与结果浮层

| 字段 | 规格 |
| --- | --- |
| 类型 | Search Input + Popover + Result List |
| 位置 | 顶部栏右侧，保持当前搜索框位置 |
| 搜索框宽度 | 推测 330 px；约占屏幕宽 18.5%；约占顶部栏内容宽 19% |
| 搜索框高度 | 推测 42 px；约占页面高 4.5%；约占顶部栏高 62% |
| 浮层宽度 | 推测 440 px；约占屏幕宽 24.7%；约为搜索框宽 133% |
| 浮层高度 | 自适应，最大 420 px；约占页面高 44.6%；结果区内部滚动 |
| 间距 | 浮层距搜索框底部 8 px；内部 Padding 12 px；结果行间距 6 px |
| 圆角 | 搜索框 18 px；浮层 20 px |
| 背景 | `rgba(241, 251, 255, 0.94)`，保留一次轻量毛玻璃，不叠加多层滤镜 |
| 边框 | 1 px `rgba(104, 190, 232, 0.35)` |
| 阴影 | `0 18px 50px rgba(38, 126, 174, 0.18)` |
| 图标 | 搜索图标 18 × 18 px，约占搜索框高 43%；结果类型图标 16 × 16 px |
| 文字 | 输入 14 px/22 px/500；分组标题 12 px/18 px/700；结果标题 14 px/20 px/650；摘要 12 px/18 px/400 |
| 层级 | 浮层位于页面内容之上、Toast 之下，建议 z-index 40 |

交互规则：

- 输入为空并提交：不显示成功提示，显示「请输入项目、角色、场景、分镜或台词关键词」，焦点留在输入框。
- 输入关键词并提交：只搜索当前本地项目与最近项目元数据，不发起网络请求。
- 结果按「项目 / 角色 / 场景 / 分镜 / 台词」分组；最多显示 12 条，超出部分在浮层内滚动。
- 点击项目结果进入项目概览；角色进入角色页并选中角色；场景或台词进入剧本页并选中场景；分镜进入分镜页并选中镜头。
- 无结果显示搜索图标、关键词和「未找到本地结果」，不得显示“已搜索成功”。
- `Escape` 关闭浮层并把焦点还给搜索框；点击浮层外关闭；切换页面时关闭。
- Loading：本地同步检索不显示骨架屏；若未来改为异步，只在 150ms 后显示轻量加载状态，避免闪烁。
- 长文本：标题单行省略，摘要最多两行；中文、数字和英文均允许匹配。

### 4.2 故事简介展开/收起

| 字段 | 规格 |
| --- | --- |
| 类型 | Expandable Text Card |
| 位置 | 项目概览右侧「故事简介」卡片底部 |
| 卡片宽度 | 沿用现状，推测约 420 px；约占屏幕宽 23.6% |
| 收起高度 | 正文最多 4 行，推测 96 px；约占卡片内容高 45% |
| 展开高度 | 自适应，建议最大 260 px；超出时卡片内部滚动 |
| 按钮尺寸 | 96 × 36 px；约占卡片宽 23%；点击目标不小于 36 px 高 |
| 圆角 | 按钮 14 px |
| 文字 | 正文 14 px/24 px/400；按钮 13 px/20 px/650 |

交互规则：

- 默认保持当前四行摘要视觉。
- 点击「展开全部」后展示完整正文，按钮变为「收起」，Chevron 旋转 180°。
- 再次点击恢复收起状态；切换项目时恢复收起，避免继承错误状态。
- 正文少于或等于四行时隐藏按钮，不制造无意义入口。
- 展开和收起只做高度与透明度过渡，时长 160–200ms；支持 `prefers-reduced-motion`。

### 4.3 角色声音真实入口

| 字段 | 规格 |
| --- | --- |
| 类型 | Navigation Action Card |
| 位置 | 角色页右侧检查器「声音」区域 |
| 区域宽度 | 沿用右侧栏，推测约 310 px；约占屏幕宽 17.4% |
| 区域高度 | 推测 92 px；约占页面高 9.8% |
| 按钮尺寸 | 推测 108 × 36 px；约占区域宽 35%；约占区域高 39% |
| 图标 | 麦克风或右箭头 16 × 16 px；约占按钮高 44% |
| 背景 | 天蓝半透明次级按钮；Hover 提升边框亮度，不使用伪播放波形动画 |
| 文字 | 「前往配音」13 px/20 px/650；音色摘要 12 px/18 px/400 |

交互规则：

- 移除无事件的圆形播放按钮。
- 显示当前角色音色摘要，并提供「前往配音」按钮。
- 点击后进入配音页，同时将当前角色设为说话人筛选条件。
- 若当前角色没有台词，配音页进入该角色空态，并提供「新增台词」入口。
- 真实音频只能在配音页本地试听；未接入 Provider 时不伪造音频播放。

### 4.4 缺失素材导出确认弹窗

| 字段 | 规格 |
| --- | --- |
| 类型 | Modal / Destructive-risk Confirmation |
| 位置 | 成片页居中浮层 |
| 宽度 | 推测 620 px；约占屏幕宽 34.8% |
| 高度 | 自适应，推测 390–440 px；约占页面高 41.4%–46.7% |
| 遮罩 | `rgba(22, 67, 92, 0.28)` + 4 px 轻模糊；不叠加额外大面积毛玻璃 |
| Padding | 28 px；约占弹窗宽 4.5% |
| 圆角 | 24 px |
| 边框 | 1 px `rgba(255,255,255,0.72)` |
| 标题 | 22 px/30 px/750，「素材尚未完整」 |
| 状态卡 | 三列，每列约占内容宽 31%；最小高 76 px |
| 按钮 | 各 150 × 44 px；约占弹窗宽 24%；点击目标 44 px |

弹窗文案与状态：

- 标题：「素材尚未完整」
- 说明：「继续导出会使用占位画面、静音或无字幕降级，原项目素材不会被修改。」
- 状态卡只展示存在缺失的类型，例如「画面缺失 6 项」「配音缺失 6 项」「字幕缺失 2 项」。
- 次按钮：「返回补充素材」；主按钮：「仍然导出」。
- 全部素材完整时不弹窗，直接打开保存位置选择。
- 点击「仍然导出」后才进入文件选择和 FFmpeg 渲染；取消不得产生临时任务、导出记录或进度状态。
- `Escape` 等同取消；初始焦点放在「返回补充素材」；焦点限制在弹窗内。
- 导出进行中不得重复打开确认弹窗。

## 5. 页面尺寸比例

| 区域 | x / y（相对整页） | 宽 / 高（相对整页） | 滚动与层级 |
| --- | --- | --- | --- |
| 顶部栏 | 推测 `1.3% / 1.6%` | `97.4% / 7.2%` | 固定，z-index 30 |
| 搜索结果浮层 | 推测 `70.5% / 8.6%` | `24.7% / ≤44.6%` | 内部滚动，z-index 40 |
| 故事简介卡 | 推测 `72% / 49%` | `24% / 28%–44%` | 展开时内容区自适应 |
| 角色声音区域 | 推测 `80% / 67%` | `17.4% / 9.8%` | 随右侧检查器滚动 |
| 导出确认弹窗 | 推测 `32.6% / 27%` | `34.8% / 41.4%–46.7%` | 居中固定，z-index 60 |
| Toast | 推测 `82% / 88%` | `16% / 7%` | 位于所有普通浮层之上，z-index 80 |

所有位置与尺寸均为 1783 × 942 截图推测值；实现应优先复用当前 CSS token 与响应式容器。

## 6. 状态与异常覆盖

- Search：idle、focused、results、empty、invalid、selected、closed。
- Story：collapsed、expanded、no-toggle、long-text。
- Voice entry：normal、pressed、角色无台词后的配音空态、Provider 未配置。
- Export：ready、missing-image、missing-audio、missing-subtitle、confirm-open、cancel、exporting、failed。
- Disabled：导出中禁用导出按钮；没有镜头时保持当前禁用逻辑。
- 小屏：宽度小于 1180 px 时搜索浮层宽度改为 `min(440px, calc(100vw - 32px))`；导出弹窗宽度不超过 `calc(100vw - 40px)`。
- 长文本：结果标题和项目路径省略；弹窗说明允许两行；故事全文内部滚动。
- 暗色模式：当前产品没有完整暗色 token，本轮不新增半成品暗色模式。
- 横竖屏：Windows 桌面仅验收横向窗口；最小窗口尺寸沿用 Electron 当前限制。
- 无障碍：所有按钮保留可见焦点；Popover 使用列表语义；Modal 使用 `role="dialog"` 与 `aria-modal="true"`。

## 7. React / Electron 实现映射

- `TopBar`：只负责输入、浮层和结果点击；搜索聚合放入本地纯函数 Service，避免在 JSX 中散落业务规则。
- `App`：持有当前选择状态并处理搜索结果导航，复用现有 `selectedCharacter`、`selectedScene`、`selectedShot`、`selectedSpeaker`。
- `OverviewPage`：只增加故事简介展开状态，不改变项目数据。
- `CharacterPage`：声音按钮改为真实导航动作，不调用外部 Provider。
- `FinalPage`：增加缺失素材确认状态；真正导出仍由 `videoExportRepository` 执行。
- `main.js` / `preload.cjs`：本轮 UI 闭环不需要扩大 IPC 权限。
- 建议新增搜索 Service 单元测试，以及搜索、展开、角色跳转、导出确认四项 UI 回归测试。

## 8. 设计规范总结

- Color：沿用 V22 天蓝渐变与深蓝文字；风险提示只使用低饱和琥珀，不使用大面积红色。
- Typography：系统中文无衬线；标题 20–22 px，正文 13–14 px，辅助文字 12 px。
- Button：主按钮天蓝渐变，次按钮浅蓝玻璃；任何可见按钮必须有真实动作或明确 Disabled。
- Card：只在浮层和重要确认区域使用一次毛玻璃；普通信息块用半透明纯色降低合成开销。
- Motion：160–200ms；尊重减少动态效果偏好；页面切换不新增复杂动画。
- Privacy：搜索、跳转、展开、导出确认均为本地行为；不读取或上传 API Key。

## 9. 验收标准

1. 搜索一个已存在角色可看到真实结果，点击后进入角色页并选中该角色。
2. 搜索不存在内容显示空态，不出现虚假成功 Toast。
3. 故事简介可展开、收起；短内容不显示展开按钮。
4. 角色声音按钮进入配音页并选中对应角色。
5. 缺图或缺音时点击导出先显示确认；取消不触发文件选择；继续才开始导出。
6. 素材完整时仍保持一步导出，不增加无意义确认。
7. `lint`、`build`、既有 16 项严格回归和新增 UI 回归全部通过。
8. 重新生成 Windows x64 安装包，并复核 ASAR、启动响应、哈希与签名状态。

## 11. 不确定项与设计假设

- 搜索默认覆盖当前项目完整内容和最近项目元数据，不打开或解析其他 `.manju` 文件正文。
- 角色页没有独立角色音频字段，因此声音入口跳转到配音页，而不是伪造播放状态。
- 缺失素材降级导出仍是产品允许的能力，本轮只增加知情确认，不改 FFmpeg 降级策略。
- Windows 代码签名需要有效证书及其使用授权；没有证书时只能重新打包并如实报告 `NotSigned`。
