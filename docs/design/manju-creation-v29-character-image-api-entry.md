# 漫剧制作 V29：角色图片 API 生成入口设计稿

## 1. 问题与目标

当前角色模块只有“导入参考图”，虽然设置页已经声明百炼图片能力，并映射 `qwen-image-2.0-pro`，但角色页没有对应的 API 图片生成入口，用户无法从角色工作流发现该能力。

本次目标是在角色页补齐一个真实、可理解、不会误扣费的“API 生成角色图”入口，并预留后续文生图、参考图生成和生成结果确认流程。

当前用户要求“不能欠费、只使用免费能力”，因此首期入口必须遵守：

- 入口可见、可点击、状态真实。
- 点击后打开 API 生成面板，而不是无反应或假生成。
- 当前付费总开关关闭时，不发送百炼生成请求。
- 不显示随机结果、模拟成功、模拟排队或虚构额度。
- 只有未来真实请求成功、图片下载到本机且用户确认采用后，才写入角色图片与统一素材库。

## 2. 来源与基准

- 页面基准：现有 `CharacterPage` 三栏角色设定布局。
- 视觉来源：`docs/design/manju-creation-v8-launchpad-character-bible.png`。
- 运行视觉：天蓝渐变、明亮毛玻璃、蓝青主操作、细描边和柔和辉光。
- 目标平台：Windows Electron，基准内容画布 1440 × 900。
- 当前真实能力：设置页可识别百炼图片 Provider 并执行鉴权探测；真实图片执行器尚未开放。
- 当前付费边界：Electron 主进程固定 `allowPaidGeneration: false`。

## 3. 页面改动范围

不重构角色页，只修改左侧角色索引栏操作区，并新增一个角色图片 API 面板。运行截图验收发现多角色列表会把底部操作挤出首屏，因此实现时将该操作区放在“新建角色”下方、角色列表上方，以保证入口始终可发现；按钮与“导入参考图”的相对顺序保持不变。

```text
CharacterPage
├─ CharacterIndex
│  ├─ 新建角色
│  ├─ CharacterImageActions
│     ├─ API 生成角色图
│     └─ 导入参考图
│  └─ 角色列表（独立滚动）
├─ CharacterCanvas
├─ CharacterInspector
└─ CharacterImageApiDialog
```

## 4. “API 生成角色图”按钮

| 字段 | 规格 |
| --- | --- |
| 类型 | Button |
| 位置 | 左侧角色栏顶部操作区，位于“新建角色”下方和“导入参考图”上方 |
| 宽度 | 约 100% 父容器；约 190–220 px；约 14% 屏幕宽度 |
| 高度 | 38 px；约角色栏高度 5%；约页面高度 4.2% |
| 间距 | 与导入按钮垂直间距 8 px |
| 圆角 | 12 px |
| 背景 | `linear-gradient(135deg, #68D7FA, #299EE4 58%, #4C83EA)` |
| 边框 | 1 px `rgba(255,255,255,0.76)` |
| 阴影 | `0 10px 22px rgba(29,142,205,0.20)` |
| 图标 | Spark，16 × 16 px，约按钮高度 42% |
| 主文案 | `API 生成角色图`，12 px，700 |
| 状态标记 | 付费锁定时显示 12 × 12 px Lock 图标或“已锁定”短标签 |
| 点击区域 | 不小于 38 px 高，整行可点击 |

按钮状态：

- 未找到 Key：按钮可点击；打开面板后显示“未找到本地百炼 Key”，提供“前往设置”。
- Key 已接入、付费锁定：按钮可点击；打开面板展示模型、提示词和参考图，但提交按钮显示“生成已锁定”。
- 接口探测失败：按钮仍可进入面板；状态卡显示真实错误和“前往设置”。
- 未来允许真实生成：按钮文案不变；面板提交前必须先执行本地请求预检和费用确认。
- 处理中：按钮显示真实进度状态并禁止重复提交。

不允许把按钮直接设为完全禁用，因为用户需要通过它理解为什么当前不能生成以及应该去哪里配置。

## 5. 角色图片 API 面板

### 5.1 整体尺寸

- 类型：Modal Dialog。
- 宽度：约 620 px；约 43% 屏幕宽度；最大 `calc(100vw - 32px)`。
- 高度：约 650 px；约页面高度 72%；小窗口使用 `max-height: calc(100vh - 32px)` 并内部滚动。
- 圆角：22 px。
- 背景：`rgba(248,253,255,0.94)` 强毛玻璃。
- 模糊：24 px。
- 遮罩：`rgba(31,80,110,0.28)` 并使用 10–12 px 背景模糊。
- z-index：高于角色页面、顶部导航和提示条。

### 5.2 面板结构

```text
CharacterImageApiDialog
├─ DialogHeader
│  ├─ Image/Spark Icon
│  ├─ Title: API 生成角色图
│  ├─ Character Name
│  └─ Close Button
├─ ProviderStatusCard
│  ├─ Provider: 阿里云百炼
│  ├─ Model: qwen-image-2.0-pro
│  ├─ Key Status
│  └─ Paid Lock Status
├─ CharacterReferencePreview
│  ├─ Current Character Image or Empty Placeholder
│  └─ Reference Usage Label
├─ PromptEditor
│  ├─ Prompt Textarea
│  └─ Character Counter
├─ GenerationOptions
│  ├─ Size Select
│  ├─ Image Count: fixed 1
│  └─ Watermark: off
├─ CostSafetyNotice
├─ ErrorOrResultArea
└─ DialogActions
   ├─ Cancel
   ├─ Go To Settings
   └─ Generate / 生成已锁定
```

### 5.3 Provider 状态卡

- 宽度：100% 父容器；高度约 72 px；约面板高度 11%。
- 四列信息：Provider、模型、Key、生成权限。
- Provider 和模型只展示当前真实配置。
- 生成权限状态：
  - 绿色：真实执行已授权。
  - 橙色：Key 已接入但付费生成锁定。
  - 红色：Key 缺失或接口异常。
- 当前生产版本默认显示橙色“付费生成已锁定”。

### 5.4 参考图区域

- 宽度：约 160 px；占内容区约 28%。
- 高度：约 210 px；9:16 竖版预览。
- 有真实角色图时显示当前图，并标注“将作为角色一致性参考”。
- 无真实角色图时显示明确空态“当前角色没有参考图，将使用文生图”。
- 不使用 `Art` 演示画面冒充真实参考图。

### 5.5 提示词编辑区

- 宽度：其余内容区约 68%。
- Textarea 高度：约 150 px。
- 初始提示词只能由当前真实角色字段确定性组合：角色名、角色定位、声音气质、人物关系；缺失字段不虚构。
- 用户可以编辑提示词。
- 最大 1500 字符；显示实时字符数。
- 初始中文结构示例：

```text
角色设定图，角色：林夏；角色定位：调查记者；保持人物身份一致；干净背景；正面半身角色设计；适合漫剧分镜连续性使用。
```

### 5.6 生成选项

- 图片数量固定为 1，降低不可预测费用。
- 尺寸列表必须来自执行服务允许值，未核验前不把任意尺寸发送到接口。
- `watermark: false`。
- 使用现有参考图时最多传 1 张角色图；后续需要场景/服装融合时再扩展为最多 3 张。

### 5.7 费用与锁定提示

当前状态文案：

```text
付费生成已锁定
本次只展示请求配置，不会向百炼发送图片生成请求，也不会消耗额度。
```

- 使用盾牌或锁图标。
- 不展示无法实时核验的“剩余额度”或“本次免费”。
- 未来真实执行前必须再次弹出费用确认；免费额度不等于绝对不会计费。

### 5.8 底部操作

- “取消”：关闭面板，无副作用。
- “前往设置”：关闭面板并进入设置页，选中图片能力。
- “生成已锁定”：当前禁用，tooltip 说明“为了避免产生费用，真实图片生成总开关尚未开启”。
- 未来真实生成按钮：必须在 Key、接口、提示词和费用确认均通过后才可用。

## 6. 未来真实执行流程

```text
点击 API 生成角色图
→ 检查角色真实字段
→ 打开面板并本地生成请求预览
→ 用户编辑提示词
→ 本地 dry-run 校验
→ 费用确认
→ Electron 主进程发送百炼请求
→ 验证 HTTP 成功和返回结构
→ 立即下载临时图片到本机
→ 展示真实结果预览
→ 用户选择“采用此图”
→ 写入 character.image
→ 统一素材库自动派生新素材
→ 进入 .manju 自动保存
```

失败时不得修改现有角色图，不得标记角色图已完成，不得显示模拟结果。

## 7. 状态与异常

- Loading：只有真实请求开始后显示；当前锁定状态不能显示加载动画。
- Empty：无角色图时只显示空态，不渲染装饰图冒充参考图。
- Error：显示真实错误码/简化说明，保留当前角色图。
- Locked：可查看配置，但提交按钮禁用。
- Success Preview：真实图片已经下载到本地，但尚未采用。
- Adopted：用户确认后写入项目，并显示本机文件来源。
- Long text：提示词区域内部滚动，角色名最多两行。
- Small window：面板内部滚动，底部操作吸附。
- Reduced motion：关闭面板缩放动画，只保留淡入淡出。
- Dark mode：当前项目不支持，保持明亮天蓝视觉。

## 9. 验收标准

1. 角色页每个真实角色都能看到“API 生成角色图”入口。
2. 点击按钮必有真实状态反馈，不能无反应。
3. 当前硬锁下网络图片生成请求数为 0。
4. 面板显示实际 Provider、模型、Key 状态和付费锁状态。
5. 提示词只使用当前角色真实字段，不填充演示人设。
6. 当前角色图只作为真实参考图展示，不使用默认 `Art` 替代。
7. 当前锁定状态不能出现模拟队列、模拟进度或模拟结果。
8. 进入设置能自动定位图片能力。
9. 键盘焦点、Escape、背景关闭和返回焦点正确。
10. 角色页原有导入参考图、角色编辑和配音入口不受影响。

## 10. 设计置信度

- 功能缺口判断：100%。
- 页面插入位置：98%。
- 视觉方向：99%，沿用已确认的天蓝渐变毛玻璃。
- 组件尺寸：94%，需在 1440 × 900 和 125%/150% 缩放下微调。
- API 安全边界：100%，当前付费硬锁不允许生成请求。

本设计稿仅补充角色图片 API 入口，不授权开启真实付费生成。
