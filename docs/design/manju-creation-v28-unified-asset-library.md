# 漫剧制作 V28：统一素材库页面设计稿

## 1. 设计目标

将当前分散在“角色设定、分镜制作、配音工作台、成片合成”中的真实用户素材，汇总为一个可检索、可定位、可替换、可安全移除的统一素材库。

本页面只展示用户实际导入、编辑或保存到当前 `.manju` 项目中的素材，不生成模拟缩略图、模拟波形、模拟配音或虚构统计。AI 生成能力继续保持未接入状态，仅保留现有 Provider 接口边界。

核心价值：

- 统一查看当前项目内的角色参考图、分镜图片、角色配音、背景音乐和音效。
- 快速判断素材是否缺失、是否被引用、被哪些角色/镜头/台词/音轨使用。
- 从素材反向定位到业务页面，减少跨页面查找成本。
- 在替换或移除前明确展示影响范围，避免误删后破坏成片。
- 直观展示 `.manju` 项目容量占用，避免保存时才发现超过 10 MB。

## 2. 范围与边界

### 2.1 首期范围

- 素材分类、真实数量统计与容量统计。
- 按类型、状态、引用情况筛选。
- 按名称、角色、场景、台词搜索。
- 卡片视图与紧凑列表视图切换。
- 查看素材详情、文件名、类型、容量、来源和使用位置。
- 一键定位到角色、分镜、配音或成片页面中的具体使用处。
- 单素材替换、下载/另存、移除。
- 对引用中素材执行替换或移除前的影响确认。
- 无引用素材识别与安全清理入口。
- 损坏、缺失或无法解码素材的明确错误态。

### 2.2 本期不做

- 不调用阿里云百炼或其他付费模型。
- 不自动生成图片、语音、视频或波形假数据。
- 不引入云端素材库、账号同步、协同共享或发行能力。
- 不新建独立数据库复制现有素材；`.manju` 项目仍是唯一数据源。
- 不在首期做文件夹批量扫描、内容哈希去重和外部文件自动监听。
- 不把已导出的 MP4 作为可编辑源素材；后续可增加只读“成片记录”。

## 3. 来源与设计基准

### 3.1 项目证据

- 当前顶部导航中的“素材”实际复用角色页面，需要改为独立素材库入口。
- `characters` 保存角色信息和角色参考图。
- `shots` 保存分镜图片、文件名、状态和镜头关联信息。
- `lines` 保存角色台词、配音音频、文件名和说话人信息。
- `audioTracks` 保存背景音乐、音效、时长、音量、波形和时间位置。
- 当前项目文件限制为 10 MB；单张图片限制为 2 MB，单个音频限制为 3 MB。

### 3.3 画布与平台假设

- 目标平台：Windows 桌面端 Electron EXE。
- 基准画布：1440 × 900；最低有效内容区按 1180 × 720 设计。
- Windows 缩放：重点验证 100%、125%、150%。
- 顶部应用壳、窗口控制区和主导航沿用现有结构，不重做全局框架。
- 主内容区支持纵向滚动；左右侧栏内部区域可独立滚动。
- 继续使用明亮天蓝渐变、半透明毛玻璃、细描边和柔和蓝色辉光。
- 当前版本不增加暗色主题；暗色模式只保留未来 token 扩展能力。

### 5.2 响应式规则

- 宽度 ≥ 1360 px：三栏常驻，右侧检查器宽度 24%。
- 宽度 1180–1359 px：左栏缩为图标 + 短标签，右栏宽度 25%，素材卡片最少两列。
- 宽度 < 1180 px：左栏变为筛选弹层，右侧检查器变为抽屉，中部使用全部宽度。
- 高度 < 760 px：标题区压缩为单行，容量条移入工具栏右侧。
- 125%/150% 缩放时不允许出现横向页面滚动；卡片列数自动减少。

## 7. 组件详细设计

### 7.1 页面标题与项目容量

- 相对页面宽度 100%、高度 10%。
- 左侧 62%：标题“素材库”，副标题“统一管理当前项目中的真实图片与音频素材”。
- 右侧 34%：项目容量卡，展示 `已使用 / 10 MB`、进度条、素材总数。
- 进度条占容量卡宽度 58%、高度 6 px。
- 0–69% 使用主蓝色；70–89% 使用橙色；≥90% 使用红色。
- 容量计算只能来自当前项目实际可序列化数据，不使用估算展示冒充精确值；若只能估算，文案明确标注“约”。

### 7.2 工具栏

- 高度约 54 px，玻璃卡片圆角 16 px。
- 搜索框占工具栏宽度 42%，最小宽度 320 px；图标宽高约输入框高度的 38%。
- 搜索占位：“搜索素材名称、角色、场景或台词”。
- “导入素材”主按钮占工具栏宽度约 11%，高度 36 px。
- 排序下拉占 11%，默认“最近使用”。
- 视图切换占 7%，含卡片与列表两个图标按钮。
- 结果计数靠右显示，如“共 18 个真实素材”。
- 导入菜单按类型显示：导入图片、导入音频；文件校验沿用项目已有大小和格式限制。

### 7.3 左侧分类与筛选

- 面板圆角 18 px，内边距为面板宽度的 8%。
- 每个分类项高度 40 px，图标占分类项高度 40%，数量徽标靠右。
- 分类：全部素材、角色图片、分镜图片、角色配音、背景音乐、音效。
- 状态筛选：全部状态、已引用、未使用、缺失/损坏。
- 当前选中项使用浅蓝渐变底、1 px 蓝色边框和左侧 3 px 强调条。
- 数量必须实时由 canonical project data 推导；数量为 0 仍显示，不隐藏分类。

### 7.4 中部素材卡片

- 默认三列；中等窗口两列；最窄单列。
- 卡片间距 14 px，圆角 16 px，卡片宽度约中部内容区的 31.5%。
- 图片卡片预览区宽度 100%、高宽比 16:10；使用 `object-fit: cover`。
- 音频卡片预览区宽度 100%、高度约卡片的 42%；只显示从真实音频解析得到的波形。无法解析时显示音频图标和真实时长/文件信息，不绘制随机波形。
- 卡片信息区占卡片高度约 38%，包含名称、类型、来源、容量和引用数量。
- 状态徽标位于预览区右上角；选中框位于左上角。
- 悬停显示“查看详情”“定位到使用处”快捷按钮。
- 选中态使用 2 px 主蓝描边与 8% 蓝色辉光，不通过大幅缩放造成布局抖动。
- 缺失/损坏态不显示伪预览，改为红色线框占位、错误原因和“替换素材”按钮。

### 7.5 紧凑列表视图

- 行高 58 px，表头高 40 px。
- 列：选择 5%、预览 8%、名称 27%、类型 12%、来源 18%、使用次数 12%、大小 10%、状态 8%。
- 列表表头吸顶；长列表仅中部区域滚动。
- 点击行选择素材；双击或点击定位按钮跳转使用处，不把整行双击作为唯一入口。

### 7.6 右侧素材检查器

- 面板圆角 18 px，背景使用较强毛玻璃，避免底层卡片干扰阅读。
- 顶部预览占检查器高度 28%。
- 基本信息占 20%：素材名、文件名、格式、大小、来源、更新时间。
- 使用位置占 34%，列表项高度 48–64 px。
- 操作区占 18%，固定在面板底部。
- 使用位置示例：
  - “角色 · 林夏 · 参考图”
  - “第 03 镜 · 雨夜车站 · 分镜图”
  - “第 12 句 · 林夏 · 角色配音”
  - “成片时间线 · 00:12.4 · 背景音乐”
- 每个引用项带“定位”按钮；点击后切换对应顶部页面并选中业务实体。
- 操作按钮：定位到使用处、替换、另存为、移除。
- 未选中素材时显示引导空态，不显示禁用的破坏性按钮堆叠。

### 7.7 批量操作栏

- 仅在选中一个或多个素材时，从中部底部浮现。
- 高度 52 px、左右各距中部区域 16 px，使用强毛玻璃和蓝色描边。
- 显示“已选择 N 项”、取消选择、另存、清理未使用素材。
- 批量移除默认只允许未引用素材；包含已引用素材时必须进入影响确认列表。

### 7.8 弹窗与确认

替换确认弹窗：

- 宽度约窗口的 38%，最小 520 px。
- 展示旧素材、新素材、大小差异、将受影响的引用数量。
- 明确文案：“替换后，所有使用此素材的位置将同步更新。”
- 操作：取消、确认替换。

移除确认弹窗：

- 未引用素材使用普通确认。
- 已引用素材使用高风险确认，逐项列出受影响位置。
- 明确说明移除只清除媒体字段，不删除角色、镜头、台词或音轨以外的业务数据；涉及整个音轨删除时需单独提示。
- 操作：取消、移除素材；危险按钮使用红色但面积不超过主弹窗操作区的 30%。

## 8. 状态与交互规则

### 8.1 空状态

- 全项目无素材：标题“暂无真实素材”，说明“从角色、分镜、配音或成片页面导入后，会自动汇总到这里。”
- 提供“导入素材”与“前往角色设定”两个入口。
- 分类无结果：说明当前分类没有实际素材，不展示演示卡片。
- 搜索无结果：保留搜索词，提供清除筛选按钮。

### 8.2 加载状态

- 本地索引计算通常应即时完成；较大项目仅对中部列表使用 3–6 个骨架卡片。
- 加载超过 800 ms 才显示骨架，避免快速闪烁。
- 不阻塞顶部导航和返回操作。

### 8.3 错误状态

- Data URL 格式无效：标记“素材损坏”。
- 文件类型不支持：导入时阻止并显示支持格式。
- 图片超过 2 MB、音频超过 3 MB：阻止导入并显示实际大小与限制。
- 项目预计超过 10 MB：替换/导入前预警，不等保存失败后才提示。
- 本地另存失败：保留素材不变，显示可重试通知。

### 8.4 选择与定位

- 单击卡片：选中并打开右侧详情。
- `Ctrl`/`Shift`：多选，符合 Windows 桌面交互习惯。
- “定位到使用处”：跳转到对应页面，并通过稳定实体 ID 选中具体角色、镜头、台词或音轨。
- 一个素材存在多个引用时，先在右侧选择引用位置，不默认跳第一个造成误解。

### 8.5 替换与移除

- 替换素材不创建第二套引用关系，而是更新 canonical entity 中原有媒体字段。
- 替换完成后重新派生素材索引、容量统计和就绪状态。
- 移除角色图/分镜图/配音时保留对应角色、镜头和台词实体，只清除媒体字段并回到真实“未完成”状态。
- 移除 BGM/SFX 时删除对应 `audioTracks` 项，因为音轨本身即为该素材的业务实体。
- 所有危险操作完成后提供一次可见反馈；若现有状态管理无法安全撤销，不显示虚假的“撤销”按钮。

## 9. 真实数据模型与架构映射

### 9.1 索引策略

首期不新增独立素材数据库。素材库通过纯函数从项目 canonical data 派生索引：

```text
characters ───────┐
shots ────────────┤
lines ────────────┼─> assetLibraryService.buildIndex() ─> AssetLibraryPage
audioTracks ──────┘
```

每条派生素材使用稳定键：

```text
character-image:{characterId}
shot-image:{shotId}
voice-audio:{lineId}
audio-track:{trackId}
```

推荐派生类型：

```ts
type AssetKind = 'character-image' | 'shot-image' | 'voice-audio' | 'bgm' | 'sfx'
type AssetHealth = 'ready' | 'unused' | 'missing' | 'broken'

interface ProjectAssetIndexItem {
  id: string
  kind: AssetKind
  name: string
  fileName?: string
  sourceDataUrl?: string
  mimeType?: string
  estimatedBytes: number
  health: AssetHealth
  references: AssetReference[]
  canonicalEntityId: string
}
```

### 9.2 分层职责

| 层 | 职责 |
| --- | --- |
| `AssetLibraryPage` | 展示、搜索输入、筛选、选中态、弹窗开关 |
| `assetLibraryService` | 派生索引、分类统计、容量计算、健康状态、搜索与排序 |
| `App`/现有业务回调 | 更新 canonical `characters/shots/lines/audioTracks` |
| `projectRepository` | 继续负责真实 `.manju` 项目保存和加载 |
| Electron 文件能力 | 导入、另存、在资源管理器中定位；通过现有安全桥接扩展 |

页面不得直接复制大块 Data URL 形成第二份长期状态。选中素材只保存稳定 ID，需要时从派生索引读取。

### 9.3 导航映射

- 新增顶层页面 ID：`assets`。
- 顶部“素材”导航从当前 `character` 映射改为 `assets`。
- 角色页面保留原有角色编辑能力，并通过素材库引用定位进入。
- 页面跳转参数使用稳定实体 ID，不依赖显示名称或数组位置。

## 12. 可访问性与桌面交互

- 所有图标按钮必须有可见 tooltip 和 `aria-label`。
- 键盘焦点使用 2 px 高对比蓝色轮廓，不能只靠阴影。
- 卡片选择、筛选、弹窗和引用列表支持 Tab 顺序。
- 状态不只依赖颜色，同时使用文字和图标。
- 主按钮最小高度 36 px，图标按钮最小点击区域 34 × 34 px。
- 弹窗打开时锁定背景焦点，关闭后焦点返回触发按钮。
- 音频试听必须提供播放/暂停、进度和时间文字；不自动播放。

## 13. 性能约束

- 素材索引通过 `useMemo` 或等价选择器按 canonical data 变化重新计算，避免每次鼠标操作重建。
- 缩略图复用已有 Data URL，不重复解码或复制字符串。
- 大列表使用分页或虚拟化的触发阈值建议为 100 项；首期数据较少时不提前引入复杂依赖。
- 搜索输入防抖 150–250 ms；本地小数据量也可即时筛选，但要避免无意义的持久化写入。
- 右侧检查器只渲染当前选中素材的完整预览。
- 页面进入/退出不启动 Provider、轮询或后台媒体解析任务。
- 动画只使用 opacity/transform，持续 140–220 ms，并尊重减少动态效果设置。

## 14. 验收标准

1. 顶部“素材”打开独立素材库，不再误入角色页面。
2. 素材数量、分类和容量均来自当前真实项目数据。
3. 无素材项目显示真实空态，绝不出现演示卡片、随机波形或伪完成状态。
4. 角色图、分镜图、配音、BGM、SFX 能在对应分类被找到。
5. 点击使用位置能定位到正确业务页面和实体。
6. 替换后所有相关视图读取更新后的 canonical data。
7. 移除图片或配音不会误删角色、镜头或台词。
8. 移除被引用素材前必须展示影响范围。
9. 2 MB 图片、3 MB 音频和 10 MB 项目容量边界有明确反馈。
10. 进入和退出素材库无明显卡顿，125%/150% 缩放无横向溢出。
11. 键盘操作、焦点、弹窗返回和音频试听符合 Windows 桌面习惯。
12. Provider 未配置时不产生任何付费请求。
