# Contributing

This is currently a private project. Before proposing a change:

1. Open or reference an issue describing the goal and acceptance criteria.
2. Keep changes narrowly scoped and preserve existing architecture and conventions.
3. Do not modify dependencies, permissions, signing, deployment, or CI without explicit approval.
4. Run the project-standard formatting, lint, test, and build commands.
5. Report every validation command as `passed`, `failed`, or `not run`.
6. Never commit secrets, personal data, generated packages, or local runtime files.
